# 심사용 시연 영상 — 2분 촬영 시나리오

전체 내레이션 원본은 `docs/demo-script.md`, 화면 변경 이유는 `docs/ux-changes.md`. 이 문서는 그중 **심사위원에게 2분 안에 보여 줄 것만** 골라 장면·시간·동작·내레이션으로 다시 짠 촬영본이다.

## 영상이 전할 한 줄
> 혼자 지내는 어르신을 **실명 확인된 같은 동네 이웃**과 이어 주고, 대화가 **안전하게**, **동네 모임**으로 이어지게 하며, 일상의 마음까지 **함께 살핀다**.

심사 관점에서 보여 줄 것: ① 문제와 대상 ② 핵심 흐름(가입 → 이웃 → 대화 → 동네 활동) ③ 지속 참여 구조(포인트) ④ 돌봄·안전(말동무·고립 지수·두뇌 운동·긴급 도움) ⑤ 시니어를 위한 설계(그림 선택·큰 글씨)

- 내레이션은 약 1분 15초 분량(초당 약 4.5음절). 나머지는 화면만 보여 주는 여유
- 2번: '가가'는 누르지 않고 편집에서 화살표·「글씨 크기 조절」 표시만 2초 — 영상 전체는 글자 크기 '보통'으로. 인증번호·이름 입력은 2~4배속, 가입 직후 ⑧ 안전 안내는 0.5초 스쳐 지나가도 됨
- 3번(이웃 추천)은 짧게 — 추천 이웃이 세마동 분들이라는 것만 보이면 충분
- 7·8·10번은 '이런 것도 있다' 수준으로 짧게. 화면 전환은 컷으로 빠르게
- 화면 배치: 휴대폰 화면을 가운데 크게, 핵심어·설명은 왼쪽에 작고 연하게 (시선은 화면, 글은 보조)

| 뺀 것 | 이유 |
|---|---|
| 포인트 부족 안내·구독, 첫 친구 미션 진행 | 7번 포인트 화면으로 구조만 보여 줌. 수익 모델은 발표 슬라이드에서 말로 |
| 알림 설정·화면 설정·내 프로필·위치 다시 확인 | 부가 설정. 접근성은 2번 '가가'로 대신 |
| 보호자 연결 화면 | 9·10번 내레이션 "보호자와 복지사에게 알려요"로 연결 |
| 자가평가(PHQ-9·GAD-7)·짝 맞추기 | 마음 건강은 마음 날씨로, 두뇌 운동은 셈하기 한 번으로 충분 |
| 알림함·회원 탈퇴·운영자 화면 | 2분 안에서는 핵심 흐름이 아님 |

## 촬영 순서 (찍는 순서 ≠ 영상 순서)

1. **가입 (1·2번)** — 시크릿 창, 처음부터 링크 `https://green4849.github.io/SIJAK_prototype/`. 1번 연출이 잘 나올 때까지 몇 번 새로 열어 찍기. '가가'는 누르지 않음
2. **둘러보기 (3~10번)** — 새 창에서 `…/?tour` (열 때마다 시연 데이터가 처음 상태로). 3 → 4 → 5 → 6 → 7 → 8 → 9 → 10 순서로 한 번에 이어 찍기
   - 4번에서 메시지를 보낸 뒤 5번으로 가도 정덕수님 방은 그대로
   - 6번 신청 뒤 7번 포인트 화면에 +100P가 반영돼 있어 자연스럽게 이어짐
   - 6번 신청·10번 알리기는 한 번만 (다시 찍을 땐 `?tour` 로 새로 열기)
3. **11번 마무리** — 홈 화면 그림 위에 로고·슬로건은 편집에서 얹어도 됨

## 촬영 전 체크리스트

- [ ] 화면 크기: 휴대폰 세로 (실제 휴대폰 화면 녹화, 또는 PC 크롬 개발자도구 기기 모드 412×915)
- [ ] 브라우저 위치 권한 '허용' — 2번의 동네 이름은 **촬영 기기의 실제 위치**라 학교(양산동)에서 찍기. 다른 곳이면 그 동네 이름이 뜸
- [ ] 글자 크기 '보통' (영상 전체), 선명한 화면 끔
- [ ] 알림·메신저 끄기, 시계·배터리 표시 정리
- [ ] 와이파이 연결 확인 — 활동 사진은 인터넷으로 불러옴 (안 되면 아이콘으로 바뀜)
- [ ] 10번 긴급 도움·복지시설 전화는 시연용 — 실제 전화 버튼은 누르지 않기
- [ ] 내레이션은 화면 녹화 뒤 따로 녹음해서 맞추기 (말 속도에 화면을 맞추면 2분이 넘기 쉬움)
