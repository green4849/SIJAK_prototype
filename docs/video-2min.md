# 심사용 시연 영상 — 2분 촬영 시나리오

전체 내레이션 원본은 `docs/demo-script.md`, 화면 변경 이유는 `docs/ux-changes.md`. 이 문서는 그중 **심사위원에게 2분 안에 보여 줄 것만** 골라 장면·시간·동작·내레이션으로 다시 짠 촬영본이다.

## 영상이 전할 한 줄
> 혼자 지내는 어르신을 **실명 확인된 같은 동네 이웃**과 이어 주고, 온라인 대화가 **안전하게**, 그리고 **동네 모임**으로 이어지게 한다.

심사 관점에서 보여 줄 것: ① 문제와 대상 ② 핵심 흐름(가입 → 이웃 → 대화 → 동네 활동) ③ 차별점(안전·AI 말동무·고립 지수) ④ 시니어를 위한 설계(그림 선택·큰 글씨·적은 글자)

## 장면 구성 (120초)

| 6 | 1:15–1:32 | '지역생활' → 사진 있는 활동 목록(오산천·복지관) → '어르신 도시락 나눔' → '신청하기' → +100P → (컷) '가까운 복지관·경로당' 목록 「걸어서 6분 · 지금 열려 있어요」 | 온라인에서 만난 이웃이 동네 모임으로 이어지도록, 우리 동네 복지관 프로그램과 봉사에 바로 신청해요. | 온라인 → 오프라인 |

- 내레이션은 1분 20초 분량(초당 약 4.5음절). 나머지는 화면만 보여 주는 숨 쉴 틈
- 2번 장면의 인증번호·이름 입력은 2~4배속. 가입 후 ⑧ 안전 안내는 0.5초 스쳐 지나가도 됨
- 자막은 핵심어만 크게 (내레이션 전체 자막은 따로 깔되 작게)

## 뺀 것과 이유

| 뺀 것 | 이유 |
|---|---|
| 포인트 상세(모으기·쓰기, 부족 안내), 첫 친구 미션 | 수익·참여 구조는 발표 슬라이드에서 말로. 화면 +10P·+100P 알림으로 존재만 보여 줌 |
| 알림 설정·화면 설정·내 프로필·위치 다시 확인 | 부가 설정. 접근성은 8번 '가가' 한 컷으로 대신 |
| 긴급 도움(SOS)·보호자 연결 화면 | 7번 내레이션 "보호자와 복지사에게 알려요"로 연결. 시간 남으면 7번 끝에 '긴급' 버튼 1초 |
| 자가평가(PHQ-9·GAD-7)·두뇌 운동 | 기능은 좋지만 핵심 흐름(이웃 → 대화 → 동네)에서 벗어남 |
| 알림함·회원 탈퇴·운영자 화면 | 질의응답 대비용. 운영자 화면은 "B2G로 어떻게 운영하나" 질문이 나오면 바로 열 수 있게 탭에 띄워 두기 |

## 촬영 순서 (찍는 순서 ≠ 영상 순서)

1. **가입 (1·2·8번 앞부분)** — 시크릿 창, 처음부터 링크 `https://green4849.github.io/SIJAK_prototype/`. 1번 연출이 잘 나올 때까지 몇 번 새로 열어 찍기
2. **둘러보기 (3~7번)** — 새 창에서 `…/?tour` (열 때마다 시연 데이터가 처음 상태로). 3 → 4 → 5 → 6 → 7 순서로 한 번에 이어 찍기
   - 4번에서 메시지를 보낸 뒤 5번으로 가도 정덕수님 방은 그대로
   - 6번 신청은 한 번만 (두 번째 테이크는 `?tour` 로 다시 열기)
3. **8번 '가가' 클로즈업** — 시작 화면에서 따로

## 촬영 전 체크리스트

- [ ] 화면 크기: 휴대폰 세로 (실제 휴대폰 화면 녹화, 또는 PC 크롬 개발자도구 기기 모드 412×915)
- [ ] 브라우저 위치 권한 '허용' — 가입 2번의 동네 이름은 **촬영 기기의 실제 위치**라 학교(양산동)에서 찍기. 다른 곳이면 그 동네 이름이 뜸
- [ ] 글자 크기 '보통', 선명한 화면 끔 (8번 클로즈업만 '더 크게')
- [ ] 알림·메신저 끄기, 시계·배터리 표시 정리
- [ ] 와이파이 연결 확인 — 활동 사진은 인터넷으로 불러옴 (안 되면 아이콘으로 바뀜)
- [ ] 복지시설 '전화로 신청하기'는 누르지 않기 (시연 번호는 실제 기관 번호 아님)
- [ ] 내레이션은 화면 녹화 뒤 따로 녹음해서 맞추기 (말 속도에 화면을 맞추면 2분이 넘기 쉬움)
