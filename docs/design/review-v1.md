# 디자인 리뷰 v1 — 시안 정리 제안

> 2026-10-02 팀 공유 리뷰 원문. 시안(`screens-v1.png`) 기준으로 쓰였고, 구현 화면에 해당하는 항목을 A12~A15 작업으로 나눴다 (`docs/tasks/`).
> 진행 순서: **글자 체계와 여백(A12) → 색상과 카드(A13) → 아이콘과 이미지(A14) → 화면별 세부 배치(A15)**

---

현재 시안은 **큰 색면, 일러스트, 굵은 글자가 동시에 강조되어 중요한 정보의 우선순위가 흐려진다.** 또 화면마다 아이콘·카드·버튼의 표현 방식이 달라 하나의 앱이라는 통일감이 부족하다.

시니어 대상이라는 점을 고려하면 **본문과 조작 영역은 충분히 크게 유지하고, 장식의 면적과 강조 요소의 수를 줄이는 방향**이 적절하다. 기존 기능과 유저플로우를 유지하는 범위에서 정리했다.

아래 크기는 캡처에서 측정한 값이 아닌 **390px 폭의 디자인 프레임에서 시작할 제안값**이다. 실제 기기에서 조정해야 한다.

| 요소 | 제안 기준 |
|---|---|
| 화면 제목 | 24–28 |
| 카드·목록 제목 | 20–22 |
| 본문·채팅 메시지 | 18–20 |
| 보조 설명·날짜·장소 | 16–18 |
| 하단 메뉴 이름 | 14–16 |
| 화면 좌우 여백 | 20–24 |
| 카드 내부 여백 | 16–20 |
| 카드 사이 간격 | 12–16 |
| 주요 버튼 높이 | 56–60 |
| 일반 기능 아이콘 | 24–28 |
| 목록의 프로필 이미지 | 56–72 |

먼저 **모든 화면에 공통으로 적용할 수정 사항**이다.

1. **글꼴을 통일한다.** 로고를 제외한 제목·본문·버튼·숫자는 같은 글꼴을 사용한다. 화면마다 글자의 인상이 달라지는 것을 막는다.

2. **글자 굵기를 역할별로 제한한다.** 본문은 Regular, 메뉴와 버튼은 Medium, 주요 제목은 Semibold 정도로 구분한다. 현재처럼 설명까지 굵게 보이면 제목과 본문의 위계가 약해진다.

3. **장식보다 본문의 크기를 확보한다.** 친구 소개, 활동 일정, 인증 방법의 설명처럼 실제 판단에 필요한 글자가 큰 이미지와 제목에 비해 작다. 이미지 면적을 줄여 이 글자에 공간을 배정한다.

4. **본문 줄 간격을 확보한다.** 두 줄 이상의 문장은 글자 크기의 약 1.4–1.6배에서 조정한다. 큰 글자도 줄 사이가 좁으면 읽기 어렵다.

5. **줄바꿈을 정돈한다.** 제목·설명·버튼에서 단어가 어색하게 나뉘지 않도록 텍스트 영역의 폭을 조정한다. 문장을 화면에 맞추기 위해 글자 크기를 계속 줄이지 않는다.

6. **화면의 공통 정렬선을 만든다.** 제목, 설명, 필터, 카드의 왼쪽 시작점을 같은 기준에 맞춘다. 현재의 화면별 미세한 위치 차이를 없애는 것만으로도 완성도가 높아진다.

7. **간격을 일정한 규칙으로 사용한다.** 관련된 제목과 설명은 가깝게, 서로 다른 카드나 정보 묶음은 더 멀게 둔다. 모든 간격을 동일하게 만드는 것보다 정보의 관계가 드러나도록 한다.

8. **배경을 단순화한다.** 시작 화면의 종이 질감과 풍경은 브랜드 표현으로 활용하되, 친구·채팅·활동·마이페이지는 단색 배경을 중심으로 정돈한다.

9. **색상마다 역할을 정한다.** 녹색은 주요 행동과 선택 상태, 중립색은 일반 정보, 빨강은 신고·로그아웃처럼 주의가 필요한 요소에 사용한다. 화면마다 색의 의미가 달라지지 않게 한다.

10. **큰 파스텔 색면을 줄인다.** 분홍·노랑·초록 카드가 모두 크게 채워져 있어 각각이 주요 버튼처럼 보인다. 일반 카드는 밝은 중립 배경으로 두고 작은 아이콘 배경이나 포인트 영역에 색을 사용한다.

11. **그라데이션과 입체 효과를 정리한다.** 버튼·카드·아이콘에 서로 다른 광택과 명암이 들어가면 시각적 언어가 분산된다. UI 요소는 단색 중심으로 통일하는 편이 현재 앱에 적합하다.

12. **카드의 경계 표현을 통일한다.** 그림자, 테두리, 배경색 차이를 모두 겹쳐 사용하지 않는다. 일반 목록 카드는 얇은 테두리 또는 약한 그림자 중 하나를 중심으로 구분한다.

13. **둥근 모서리에도 규칙을 만든다.** 카드, 버튼, 필터를 모두 같은 알약 모양으로 만들지 않는다. 카드에는 일정한 모서리 반경을, 필터에는 둥근 형태를 사용하는 식으로 역할을 구분한다.

14. **기능 아이콘의 스타일을 통일한다.** 뒤로가기·검색·설정·전화·하단 메뉴는 선 굵기와 끝 처리, 채움 방식이 같은 아이콘 계열을 사용한다.

15. **일러스트와 기능 아이콘을 구분한다.** 인물·풍경은 친근한 일러스트로 유지하되, 검색이나 설정 같은 조작 요소는 간결한 아이콘으로 표현한다. 작은 조작 영역에 복잡한 그림을 넣지 않는다.

16. **이미지의 크기를 용도별로 정한다.** 브랜드 로고, 친구 아바타, 채팅 아바타, 활동 썸네일에 각각 크기 규칙을 만든다. 같은 인물 그림도 화면의 역할에 따라 다르게 사용한다.

17. **상단 바를 공통 부품으로 정리한다.** 화면 제목의 위치, 뒤로가기 위치, 검색·설정 아이콘의 크기와 여백을 맞춘다. 오른쪽 아이콘 유무에 따라 제목이 밀리지 않도록 한다.

18. **화살표의 사용을 정리한다.** 목록의 상세 이동은 작은 꺾쇠, 주요 행동 버튼은 필요한 경우에만 화살표를 사용한다. 화살표가 글자보다 눈에 띄지 않게 한다.

19. **선택·눌림·비활성 상태를 디자인한다.** 기본 모습만 정돈하면 실제 조작 중 완성도가 떨어진다. 색, 테두리, 아이콘의 변화 규칙을 공통으로 만든다.

20. **색상 대비를 실제 색상값으로 확인한다.** 특히 녹색 버튼 위 흰 글자, 회색 보조 설명, 채팅 입력 안내를 점검한다. 참고 기준으로 WCAG는 일반 텍스트에 4.5:1, 큰 텍스트에 3:1 이상의 대비를 요구한다. 캡처만으로 현재 디자인의 충족 여부를 확정할 수는 없다. [W3C](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

21. **아이콘 크기와 누를 수 있는 영역을 구분한다.** 그림 자체를 크게 키우기보다 주변 여백을 포함한 조작 영역을 확보한다. Android의 권장 터치 영역은 최소 48×48dp이며, 작은 아이콘도 주변 여백으로 이 영역을 확보할 수 있다. [Android Accessibility Help](https://support.google.com/accessibility/android/answer/7101858?hl=en\)

**① 시작 화면**은 브랜드 표현을 정돈해야 한다.

1. **로고·앱 이름·풍경의 강조 순서를 조정한다.** 현재는 세 요소가 모두 크게 보인다. 로고와 앱 이름을 중심으로 두고 풍경은 이를 받치는 배경으로 낮춘다.

2. **주변에 흩어진 하트를 줄인다.** 로고 안의 하트에 더해 여러 장식 하트가 반복된다. 주변 장식을 줄이면 로고 자체의 형태가 더 명확해진다.

3. **로고를 감싸는 사각 프레임을 정리한다.** 앱 아이콘 형태를 보여주려면 모서리와 내부 여백을 명확하게 통일한다. 로고 자체를 보여주려면 불필요한 프레임과 그림자를 덜어낸다.

4. **앱 이름과 슬로건 사이에 위계를 준다.** 앱 이름은 충분히 크게 유지하고 슬로건은 크기보다 읽기 좋은 대비와 간격으로 정돈한다.

5. **시작 버튼 주변을 비운다.** 식물과 풍경이 버튼 가까이 모여 있다. 버튼 주변에 일정한 단색 여백을 확보하면 행동 지점이 명확해진다.

6. **시작 버튼의 형태를 이후 주요 버튼과 맞춘다.** 인증·신청 화면과 같은 녹색, 높이, 글자 굵기를 사용해 앱의 공통 행동 스타일을 만든다.

**② 로그인·본인인증 화면**은 인증 방법의 우선순위를 명확하게 해야 한다.

1. **인사 제목의 강조를 줄인다.** 두 줄의 큰 제목과 녹색 앱 이름이 모두 강조된다. 제목 크기와 굵기를 정돈하고 실제 선택 영역에 시선이 이어지게 한다.

2. **세 선택지를 서로 다른 위계로 표현한다.** 권장하는 휴대폰 인증은 녹색 주요 버튼, 신분증 인증은 중립 배경의 보조 버튼, 도움받기는 더 낮은 강조로 구분한다. 모두 큰 색상 버튼이면 선택 기준이 흐려진다.

3. **버튼 내부를 같은 구조로 정렬한다.** 아이콘 영역, 제목 시작점, 설명 시작점을 맞춘다. 현재의 ‘왼쪽 아이콘＋중앙에 가까운 글자’ 구성을 일관된 왼쪽 정렬로 정돈한다.

4. **설명의 크기를 확보한다.** ‘가장 간편해요’, ‘가족·직원이 도와드려요’는 선택에 필요한 정보다. 제목 대비 지나치게 작게 두지 않는다.

5. **아이콘의 무게를 맞춘다.** 휴대폰 선 아이콘, 신분증 채움 아이콘, 입체적인 헤드셋의 표현을 같은 계열로 통일한다.

6. **하단 풍경과 반복 로고를 축소한다.** 시작 화면에서 이미 브랜드를 전달했다. 이 화면에서는 인증 선택지를 읽고 누르는 데 필요한 여백을 우선 확보한다.

**③ 홈 화면**은 현재 가장 큰 시각적 개선 효과를 기대할 수 있는 화면이다.

1. **세 메뉴의 배경색을 절제한다.** 분홍·초록·노랑의 큰 색면을 모두 유지하기보다, 중립 카드에 메뉴별 작은 색상 포인트를 적용한다.

2. **메뉴 아이콘을 축소하고 설명 영역을 넓힌다.** 현재는 큰 그림과 큰 제목이 공간을 많이 차지한다. 설명의 줄 길이와 여백을 확보해 메뉴 간 차이가 더 잘 읽히게 한다.

3. **세 카드의 내부 정렬을 맞춘다.** 아이콘 중심, 제목 시작점, 설명 시작점, 오른쪽 화살표 위치를 공통으로 정한다.

4. **카드 높이를 내용에 맞춰 정돈한다.** 큰 색상 버튼처럼 보이는 높이를 줄이되, 설명과 터치 영역은 유지한다. 글자가 확대되면 높이가 늘어날 수 있게 설계한다.

5. **상단 로고를 인사말보다 낮은 강조로 둔다.** 홈에서 중요한 것은 사용자와 메뉴다. 오른쪽 로고는 작은 브랜드 표시로 사용한다.

6. **하단 메뉴의 선택 표시를 바꾼다.** 홈에만 있는 노란 테두리는 주요 녹색과 연결이 약하다. 녹색 아이콘·글자와 작은 배경 표시로 통일한다.

7. **하단 메뉴의 글자 폭과 중심을 맞춘다.** ‘홈’과 ‘마이페이지’의 길이가 달라도 같은 폭 안에서 정렬한다. 긴 이름만 작은 글자로 줄이지 않는다.

**④ 동네 친구 찾기 화면**은 사람을 판단할 정보에 공간을 더 줘야 한다.

1. **상단 설명과 거리 조건을 분리한다.** 소개 문장과 ‘반경 2km 이내’가 같은 설명 덩어리로 보인다. 거리 조건은 별도의 보조 정보로 정렬해 빠르게 확인하게 한다.

2. **두 탭의 선택·미선택 모습을 통일한다.** 높이, 폭, 글자 위치를 맞추고 선택된 항목만 명확하게 강조한다.

3. **프로필 그림의 면적을 조정한다.** 큰 아바타 때문에 소개 글의 폭이 좁다. 목록용 크기로 줄이고 이름과 소개에 공간을 더 준다.

4. **이름과 나이를 구분한다.** 이름을 먼저 읽게 하고 나이는 약한 보조 정보로 같은 기준선에 배치한다. 이름과 나이 사이 간격도 일정하게 맞춘다.

5. **소개 글을 충분히 읽을 수 있게 한다.** 글자 크기를 키우고 줄 간격을 확보한다. 소개가 길어질 때 카드 높이가 늘어나도록 디자인한다.

6. **친구 신청 버튼의 크기와 위치를 정돈한다.** 소개 영역 아래 일정한 간격을 두고 배치한다. 버튼의 녹색 면적이 소개보다 더 지배적으로 보이지 않게 한다.

7. **카드 내부의 세로 간격을 통일한다.** 이름→소개→신청 버튼 사이의 간격이 사람마다 달라지지 않게 한다.

8. **목록 마지막 카드와 화면 하단 사이에 여백을 둔다.** 마지막 버튼이 홈 표시줄이나 화면 끝에 붙어 보이지 않게 한다.

**⑤ 대화 화면**은 장식보다 긴 문장의 가독성과 입력 영역이 중요하다.

1. **상단 상대방 정보의 비율을 조정한다.** 아바타, 이름, 온라인 안내의 크기를 정리해 메시지 영역과 자연스럽게 이어지게 한다.

2. **상단 조작 아이콘을 같은 기준으로 맞춘다.** 뒤로가기·전화·더보기의 그림 크기와 조작 영역을 통일한다.

3. **메시지 본문의 굵기를 낮춘다.** 대화 문장 전체가 굵게 보여 읽는 피로가 생길 수 있다. 본문은 일반 굵기를 사용하고 이름 등 필요한 곳만 강조한다.

4. **말풍선 내부 여백을 일정하게 둔다.** 위아래와 좌우 여백을 각각 정해 문장이 테두리에 가까이 붙지 않게 한다.

5. **말풍선의 최대 폭을 정한다.** 화면을 거의 가득 채우지 않도록 본문 영역의 약 75–80%부터 검토한다. 긴 메시지도 상대·본인 방향이 명확하게 보이게 한다.

6. **받은 메시지와 보낸 메시지의 강조를 맞춘다.** 배경색으로 구분하되 글자의 크기와 굵기는 동일하게 유지한다.

7. **메시지 시간의 위치를 통일한다.** 각 말풍선 아래 일정한 간격으로 정렬한다. 시간을 읽기 어렵게 흐리거나 지나치게 작게 만들지 않는다.

8. **날짜 표시의 존재감을 낮춘다.** 날짜는 대화 구분용 정보이므로 작은 중립색 표시로 두고 메시지보다 강하게 보이지 않게 한다.

9. **연속 메시지의 간격 규칙을 만든다.** 같은 사람이 연속해서 보낸 메시지는 가깝게, 상대가 바뀌는 지점은 조금 더 넓게 둔다.

10. **입력창의 안내 글자와 높이를 확보한다.** 현재 입력 영역은 대화 본문에 비해 작고 흐리다. 읽기 좋은 글자 크기와 충분한 내부 여백을 준다.

11. **추가 버튼·입력창·마이크 버튼의 중심을 맞춘다.** 세 요소가 하나의 입력 바처럼 보이도록 높이와 세로 정렬을 통일한다.

12. **키보드가 열린 모습까지 디자인한다.** 입력창, 마지막 메시지, 하단 여백이 겹치지 않는 화면을 확인해야 대화 화면의 디자인이 완성된다.

**⑥ 지역생활 화면**은 목록의 정보 구조와 이미지 사용을 정돈해야 한다.

1. **필터 사이의 간격을 명확하게 둔다.** 현재 ‘문화·여가’와 ‘건강’은 가까워 하나의 긴 영역처럼 보인다. 각각의 경계와 일정한 간격을 확보한다.

2. **필터의 내부 여백을 통일한다.** 글자 길이에 따라 폭은 달라도 좌우 여백과 높이는 같게 유지한다.

3. **활동 제목·일정·장소의 위계를 정한다.** 제목은 조금 더 굵게, 일정과 장소는 충분한 크기의 일반 본문으로 두어 세 줄이 구분되게 한다.

4. **썸네일 크기를 줄여 글자 영역을 확보한다.** 이미지가 제목·일정·장소를 좁은 폭으로 밀어내지 않도록 목록용 크기를 정한다.

5. **썸네일의 그림체를 통일한다.** 산책 장면, 스마트폰, 영화 카메라, 찻잔의 표현 방식이 서로 다르다. 같은 일러스트 계열이나 같은 이미지 처리 규칙으로 묶는다.

6. **썸네일의 배경과 잘림 기준을 맞춘다.** 같은 비율, 모서리 반경, 대상의 크기를 사용한다. 카드마다 이미지가 차지하는 인상이 달라지지 않게 한다.

7. **목록의 글자 시작점과 화살표 위치를 맞춘다.** 제목 길이에 관계없이 일정·장소는 같은 왼쪽 정렬선, 화살표는 같은 오른쪽 위치를 유지한다.

8. **카드 경계를 가볍게 만든다.** 반복되는 목록에 큰 그림자가 쌓이지 않도록 얇은 경계와 일정한 간격 중심으로 정돈한다.

9. **긴 활동명에 대응하는 카드 높이를 설계한다.** 제목이 두 줄이 되어도 일정과 장소가 눌리거나 이미지와 겹치지 않게 한다.

**⑦ 지역 활동 상세 화면**은 신청에 필요한 정보가 명확하게 읽혀야 한다.

1. **상단 이미지의 높이 기준을 정한다.** 이미지가 첫 화면을 과도하게 차지하지 않도록 화면 높이의 약 20–25%부터 검토한다. 제목과 핵심 정보를 함께 볼 수 있는 비율이 중요하다.

2. **이미지의 초점과 잘림을 지정한다.** 인물의 얼굴이나 활동 내용이 화면 폭에 따라 잘리지 않게 한다.

3. **이미지 위 버튼을 공통 스타일로 맞춘다.** 뒤로가기와 관심 표시의 원형 배경, 그림 크기, 여백을 통일한다.

4. **제목 영역의 모서리와 겹침을 정돈한다.** 이미지 아래 흰 영역이 겹치는 구조를 유지한다면 겹치는 높이와 둥근 모서리를 일정하게 만들어 의도된 레이아웃으로 보이게 한다.

5. **제목과 소개 문장의 강조 차이를 키운다.** 큰 제목 바로 아래 설명도 굵게 보여 경쟁한다. 소개는 일반 본문 굵기로 두고 간격으로 구분한다.

6. **상세 정보의 좁은 다열 배치를 풀어준다.** 현재 아이콘·항목명·값이 한 줄에 들어가 날짜와 장소의 폭이 좁다. 항목명 아래 값을 두는 방식으로 긴 정보를 자연스럽게 읽게 한다.

7. **날짜와 시간의 줄바꿈 규칙을 정한다.** 글자를 줄여 한 줄에 넣기보다 날짜와 시간을 의미 단위로 구분한다.

8. **참여 인원의 숫자 위계를 정리한다.** 현재 인원과 정원에 같은 강조를 주지 말고, 먼저 읽어야 할 숫자를 명확하게 한다.

9. **활동 소개의 가로폭과 줄 간격을 확보한다.** 아이콘 옆의 좁은 영역에 긴 설명을 몰아넣지 않는다.

10. **신청 버튼을 하단의 일관된 행동 영역으로 배치한다.** 버튼 높이와 좌우 여백을 공통 규칙에 맞추고, 본문이 버튼에 가려지지 않도록 하단 공간을 확보한다.

11. **관심 표시의 선택 상태를 디자인한다.** 선택 전후의 테두리·채움 변화가 분명하도록 하되 아이콘 위치나 크기는 바뀌지 않게 한다.

**⑧ 보안 기능 안내 화면**은 정보 카드가 버튼처럼 보이지 않도록 정돈해야 한다.

1. **상단 두 문장의 강조를 구분한다.** 두 문장이 모두 크고 굵다. 핵심 제목과 보조 설명으로 나누어 아래 안내 내용까지 자연스럽게 읽히게 한다.

2. **네 가지 큰 배경색을 줄인다.** 초록·노랑·분홍·파랑이 모두 크게 사용돼 홈 화면의 메뉴 카드와 비슷하게 보인다. 중립 카드에 작은 색상 포인트를 사용하는 편이 안내 화면에 적합하다.

3. **정보 카드의 입체감을 낮춘다.** 조작할 수 없는 안내라면 버튼과 같은 강한 그림자나 강조 표현을 피하고, 제목과 설명 중심으로 구성한다.

4. **아이콘의 표현 방식을 통일한다.** 방패, 24시간, 느낌표, 자물쇠의 선·입체감·채움 정도를 맞춘다. 특히 자물쇠만 입체적으로 보이지 않게 한다.

5. **아이콘 영역을 줄이고 설명 폭을 넓힌다.** 의미가 전달되는 크기까지만 사용해 안내 문장이 자연스럽게 읽히도록 한다.

6. **설명 길이에 맞춰 카드 높이를 조절한다.** 네 카드를 같은 높이에 억지로 맞추기보다 내부 여백을 통일한다. 긴 설명의 글자를 더 작게 만들지 않는다.

7. **카드 사이 간격과 제목 위치를 맞춘다.** 어느 카드부터 읽어도 같은 구조가 반복되도록 한다.

**⑨ 마이페이지 화면**은 프로필과 설정 목록의 비율을 조정해야 한다.

1. **프로필 이미지 크기를 정돈한다.** 큰 아바타 옆에 이름과 소개가 좁게 배치되어 있다. 이미지를 적절히 줄이고 텍스트 폭을 확보한다.

2. **이름과 나이의 정렬을 맞춘다.** 이름은 주요 정보, 나이는 보조 정보로 구분하고 같은 기준선에 배치한다.

3. **소개 글을 편하게 읽을 수 있게 한다.** 글자 크기와 줄 간격을 확보하고 긴 소개가 들어왔을 때의 높이도 설계한다.

4. **프로필 영역과 메뉴 영역 사이를 분리한다.** 일정한 여백이나 약한 구분으로 ‘내 정보’와 ‘관리 항목’의 관계를 명확하게 한다.

5. **메뉴 행의 높이와 내부 정렬을 통일한다.** 아이콘, 메뉴 이름, 개수, 화살표가 모든 행에서 같은 위치에 오도록 한다.

6. **개수 표시를 오른쪽에 일정하게 배치한다.** ‘12명·2개·5개’는 메뉴 이름보다 낮은 강조로 두되 읽기 어렵게 흐리지 않는다.

7. **메뉴 묶음의 경계를 단순화한다.** 카드 바깥 그림자와 내부 구분선이 함께 과하게 보이지 않도록 하나의 가벼운 그룹으로 정돈한다.

8. **상단 설정 아이콘도 공통 규칙에 맞춘다.** 화면 안의 설정 메뉴와 같은 아이콘 스타일을 사용하고, 다른 화면의 상단 조작 요소와 크기를 맞춘다.

9. **로그아웃의 강조를 절제한다.** 빨간 글자로 구분하되, 별도의 카드 크기나 그림자로 일반 메뉴보다 과도하게 강조하지 않는다.

마지막으로 **디자인 수정 후 반드시 확인할 항목**이다.

1. **휴대폰에서 실제 크기로 확인한다.** 여러 화면을 모아놓은 발표용 이미지에서는 글자 크기와 조작 간격을 정확하게 판단하기 어렵다.

2. **글자가 크게 설정된 화면을 확인한다.** 제목·카드·버튼 높이가 늘어나도 글자가 잘리거나 겹치지 않아야 한다. 큰 글자 설정에 대응하는 것은 플랫폼 접근성 지침에서도 강조한다. [Apple Developer Documentation](https://developer.apple.com/design/human-interface-guidelines/accessibility)

3. **화면 폭이 다른 경우를 확인한다.** 특히 인증 설명, 친구 소개, 하단 메뉴, 활동 날짜가 좁은 화면에서도 유지되는지 본다.

4. **긴 내용이 들어간 시안을 확인한다.** 긴 이름·활동명·장소·소개·채팅 문장에서도 정렬과 여백 규칙이 유지되어야 한다.

5. **이미지 원본과 확대 품질을 확인한다.** 로고·아이콘·아바타가 실제 화면에서 흐려지지 않도록 적절한 해상도나 벡터 자산을 사용한다.

6. **공통 요소를 한 번에 수정할 수 있게 정리한다.** 글자 스타일, 색상, 카드, 버튼, 상단 바, 하단 메뉴를 공통 컴포넌트로 묶어 화면마다 다시 어긋나는 것을 막는다.

수정 순서는 **글자 체계와 여백 → 색상과 카드 → 아이콘과 이미지 → 화면별 세부 배치**가 적절하다. 이 순서로 진행하면 개별 화면을 반복해서 다시 손보는 일을 줄일 수 있다.
