# 시연 영상 대본 — 시니어 6080 위피 '시작'

화면에서 걷어낸 설명 문장(A18)을 버리지 않고 **화면 순서대로** 모은 대본이다.
앱 화면은 큰 글씨·적은 글씨로 두고, 설명은 영상 내레이션·자막으로 전한다.

- **둘러보기 링크**: https://green4849.github.io/SIJAK_prototype/?tour (김시작님 계정, 친구·대화·포인트가 채워진 상태)
- **처음부터 링크**: https://green4849.github.io/SIJAK_prototype/ (가입 과정을 보여 줄 때)
- 표기: 🎬 화면에서 할 동작 · 🎙 내레이션(자막) · 「」 화면에 있던 원래 문구

## 1. 시작하기 (가입)

### ① 시작 화면
- 🎬 앱을 연다 → 새싹 줄기가 자라고 두 잎이 펼쳐지며 '시작' 로고와 슬로건, 그 아래 '시작하기' 버튼, 맨 아래 언덕 위 노부부
- 🎙 「같은 동네, 좋은 이웃과 더 따뜻한 일상으로」 — 시니어의 작지만 큰 변화, '시작'입니다.
- 🎙 (로고 의미) 두 잎은 서로 다른 두 사람이 한 줄기에서 만나는 모습이에요. 슬로건의 앞글자 '**시**니어의 **작**지만'이 곧 '시작'이고요.
- 🎬 (선택) 오른쪽 위 '가가' → 화면 글씨가 커진다
- 🎙 가입 전에도 글씨부터 크게 볼 수 있어요. 여기서 키운 크기는 나중에 화면 설정에서도 그대로 이어져요.

### ② 로그인 · 본인인증
- 🎬 '시작하기' → 인증 방법 세 가지
- 🎙 「안전한 이용을 위해 본인인증을 진행해 주세요.」 '시작'은 실명으로 확인된 이웃만 만나는 서비스예요.
- 🎙 휴대폰 인증은 「가장 간편해요」. 신분증 인증(「주민등록증·운전면허증」)은 준비 중이고,
  혼자 하기 어려운 분은 '도움받기'로 「가족·직원이 도와드려요」.
- 🎬 (선택) '신분증 인증' → 🎙 「휴대폰이 본인 명의가 아니라면 '도움받기'를 눌러 주세요.」
- 🎬 (선택) '도움받기' → 🎙 「혼자 하기 어려우시면 가까운 분께 부탁해 보세요.」 옆에서 함께 인증하면 돼요.

### 휴대폰 인증 · 인증번호
- 🎬 이름·태어난 날·전화번호 입력 → '인증번호 받기'
- 🎙 「처음 한 번만 확인하면 다음부터는 자동으로 들어가요.」
- 🎙 태어난 해는 네 자리로(「예: 1955」), 전화번호는 「숫자만 적으면 돼요」 — 줄표는 저절로 들어가요.
- 🎬 인증번호 입력 → 🎙 「문자로 받은 숫자 6개를 적어 주세요.」

### 가입 — 1/2 좋아하는 활동 · 2/2 사는 동네
- 🎬 둥근 사진 중 좋아하는 활동 두세 개 누르기 → 사진 둘레에 녹색 고리와 ✓ → 아래 '다음 ○개 골랐어요'
- 🎙 「좋아하는 것을 골라 주세요. 더 잘 맞는 친구를 추천해 드려요.」 글을 읽지 않아도 사진만 보고 고르면 돼요. 「5개까지 고를 수 있어요」 — 이걸로 친구를 추천하고 대화 주제도 골라 드려요.
- 🎙 한 화면에 질문은 하나씩만 — 위쪽 막대로 몇 단계 남았는지 보여요.
- 🎬 '위치 정보 수집 동의' 누르기 → 아래에 동네 이름이 뜸 (예: 경기도 수원시 영통구 매탄동) → '가입 완료'
- 🎙 사는 곳은 고르지 않아도 돼요. 위치 사용에 한 번 동의하면 동네를 바로 찾아 드려요. 「동네(약 1km)까지만 저장해요」 — 정확한 주소는 저장하지 않아요.
- ⚠ 시연 전 브라우저 위치 권한을 미리 '허용'으로 (실내 와이파이 위치라 동네 이름이 실제와 조금 다를 수 있음)

### ⑧ 안전 안내 (가입 직후)
- 🎬 네 가지 안전 카드 → '알겠어요, 시작할게요'
- 🎙 「안심하고 이용하세요.」
  - 실명 인증 — 「본인 확인을 마친 분들만 이용해요.」
  - 위험한 대화 자동 감지 — 「돈·계좌·비밀번호를 묻는 대화는 바로 알려 드려요.」
  - 신고 및 차단 — 「불편한 분은 바로 신고하고 차단할 수 있어요.」
  - 개인정보 보호 — 「전화번호는 암호화해서 보관하고, 다른 분께 보이지 않아요.」

## 2. 홈 · 친구 찾기

### ③ 홈
- 🎬 홈 화면 — 큰 카드 세 개, 오른쪽 위 포인트, 아래 '첫 친구 3명 사귀기'
- 🎙 친구 찾기에서는 「같은 동네 좋은 이웃을 만나보세요」, 대화하기에서는 「새로운 이웃과 이야기를 나눠요」,
  지역생활에서는 「우리 동네 다양한 활동을 함께해요」. 무엇이든 세 번 안에 닿도록 만들었어요.
- 🎙 첫 친구 미션: 「친구와 서로 한 번 이상 이야기를 나누면 1명으로 세어요」 — 아무나 추가하는 게 아니라
  진짜 대화를 나눈 친구 3명이 되면 500포인트를 드려요. (진행 표시 「1명 완료 · 2명 남았어요」)

### ④ 동네 친구 찾기 — 추천 · 평가
- 🎬 '친구' 탭 → 추천 친구 목록
- 🎙 「우리 동네의 좋은 이웃을 만나보세요.」
- 🎬 김영희님 카드에서 '만나보고 싶어요' 누르기 → +10P 알림
- 🎙 별점 대신 말로 된 버튼 세 개로 평가해요. 「이웃을 평가하면 +10P · 오늘 ○번 남았어요」 — 하루 다섯 번까지.
  「평가는 상대에게 알려지지 않아요」. 평가는 다음 추천에 반영되고, '잘 안 맞아요'를 누른 이웃은 다시 보이지 않아요.
  (다섯 번을 다 쓰면: 「오늘 평가 포인트는 다 받았어요. 평가는 계속 추천에 반영돼요」)
- 🎬 '같은 동네' 탭 → '내 위치 사용하기' (둘러보기 계정만 — 새로 가입한 분은 가입 때 동의한 위치로 바로 보여요)
- 🎙 내 위치는 「동네 정도(약 1km)」로만 저장해요. 「정확한 주소는 저장하지 않고, 다른 분께도 보이지 않아요.」

### 친구 신청 · 포인트
- 🎬 '친구 신청 · 30P' 몇 번 누르기 → 포인트가 모자라면 안내 창
- 🎙 첫 신청은 무료, 받은 신청을 수락하는 건 언제나 무료예요. 같은 분께 다시 신청해도 한 번만 내요.
- 🎙 포인트가 모자라면 결제부터 권하지 않고 '무료로 모으기'를 먼저 보여 드려요 —
  「추천 친구 평가 · 봉사모임 · 첫 친구 미션」. 구독하면 「매달 포인트가 들어와요」.

## 3. 대화 · 안전

### 대화 목록 (대화가 없을 때)
- 🎬 대화 목록 → 노부부 그림과 '아직 대화가 없어요'
- 🎙 「친구가 된 이웃과 이야기를 나눌 수 있어요.」 — 낯선 사람이 먼저 말을 걸 수 없게, 친구가 된 뒤에만 대화해요.

### ⑤ 1:1 대화 — 대화 주제 추천
- 🎬 이순자님 대화방 → '대화 주제 추천' 펼치기 → 문구 하나 누르기 → 입력칸에 들어감
- 🎙 첫마디가 제일 어렵죠. 「무슨 말을 할지 고민되세요?」 「두 분이 함께 좋아하는 '산책·등산' 이야기예요.」
  「누르면 입력칸에 들어가요.」 — 자동으로 보내지 않고, 고쳐서 직접 보내요.
- 🎬 마이크 버튼으로 음성 메시지 → 🎙 글자가 어려우면 말로 보내요.

### 안전 — 위험 대화 경고 · 신고
- 🎬 정덕수님 대화방 → 송금 이야기에 빨간 경고 → '신고하기'
- 🎙 돈·송금 이야기가 나오면 받는 사람 화면에 바로 경고가 떠요.
- 🎬 신고 이유 고르고 '신고하고 차단하기' → 🎙 「신고하면 이 분과는 더 이상 대화할 수 없어요.」

## 4. 지역생활 · 봉사

### ⑥ 지역생활
- 🎬 '지역생활' 탭 → '봉사' 분류
- 🎙 「경기도에서 함께하는 다양한 활동을 만나보세요.」(내 지역 이름이 들어가요) 복지관과 함께하는 봉사모임에 참여하면 포인트를 드려요.

- 🎙 활동마다 실제 프로그램 사진이 있어요 — 실제 서비스에서는 복지관·주민센터가 올린 사진이 들어가요.

### ⑦ 활동 상세 · 신청
- 🎬 '어르신 도시락 나눔' → '신청하기' → +100P 알림
- 🎙 활동마다 한 줄 소개가 있어요 — 예: 「복지관과 함께 이웃에게 도시락을 전해요」,
  「함께 걸으며 건강도 챙기고 좋은 이웃도 만나요!」. 정원은 「선착순」이에요.
- 🎙 봉사는 참여하면 +100P, 「신청을 취소하면 돌려드려요」.

## 5. 마이페이지

### ⑨ 내 포인트
- 🎬 마이페이지 → '내 포인트'
- 🎙 모으는 방법: 추천 친구 평가(「하루 5번까지」), 봉사모임 참여(「복지관과 함께하는 지역생활 봉사」),
  첫 친구 3명 사귀기(「서로 이야기를 나눈 친구 3명」). 쓰는 곳: 친구 신청(「첫 신청은 무료예요」 · 「같은 분께 다시 신청해도 한 번만」),
  받은 친구 신청 수락은 「언제나 무료예요」.
- 🎙 체험단 기간에는 「체험 기간이에요 · ○월 ○일까지 친구 신청에 포인트를 쓰지 않아요」.

### 알림 설정
- 🎬 마이페이지 → '알림 설정' → 받는 시간 바꾸기
- 🎙 「오늘의 추천 친구 알림」 — 「새 동네 이웃이 추천되면 알려 드려요」. 알림이 너무 잦으면 오히려 앱을 지우게 돼서
  하루 두 번까지만, 원하는 시간에 받아요. (두 개를 고른 상태에서: 「다른 시간을 고르려면 하나를 먼저 꺼 주세요」)
  밤 9시부터 아침 8시까지는 보내지 않아요.

### 화면 설정
- 🎬 '글자 크기 · 화면 설정' → '아주 크게', '선명한 화면'
- 🎙 글자 크기는 네 단계 — 「누르는 즉시 바뀌어요」. 「'선명한 화면'은 검은 바탕에 밝은 글씨예요」.
  진동은 「저장·신청 같은 일을 마치면 짧게 진동해요 (지원하는 휴대폰만)」. 「이 설정은 지금 쓰시는 휴대폰에만 저장돼요.」

### 내 프로필
- 🎬 '내 프로필 관리' → 한 줄 소개
- 🎙 한 줄 소개는 이웃에게 보여요 — 「예: 산책과 옛날 노래를 좋아해요」.

### 위치 다시 확인
- 🎬 마이페이지 → '위치 다시 확인' (오른쪽에 지금 사는 곳)
- 🎙 이사하셨다면 여기 한 번만 누르세요. 지금 위치로 사는 곳과 동네 이웃을 새로 맞춰 드려요.

## 6. 말동무 (AI) — 화면·시연 데이터

> 백엔드 없이 데모에서만 동작해요 (답은 시연용 규칙). 실제 서비스에서는 음성 인식 → 정서 분석 → AI 답 → 안전 검사 → 음성 합성 순서로 처리됩니다.

### 홈 → 말동무
- 🎬 홈 네 번째 카드 '말동무' → 어제 저녁 나눈 이야기와 오늘 아침 인사가 보인다
- 🎙 말동무는 먼저 안부를 묻고, 지난 이야기를 기억해요. 언제든 말을 걸면 돼요.
- 🎬 '듣기' → 말동무 답을 소리로 읽어 준다

### 말로 하기
- 🎬 '말하기' → '듣고 있어요' → '다 말했어요'
- 🎙 글자를 치기 어려우시면 말로 하세요. 말로 물어보면 답도 소리로 들려 드려요.
  (시연에서는 「오늘은 비가 와서 마음이 좀 가라앉네요」처럼 미리 정한 말이 차례로 받아써져요)

### 마음을 살피고, 동네로 이어 주기
- 🎬 「요즘 좀 외로워요」 → 공감하는 답 + 동네 활동 카드(건강 걷기 모임) → 누르면 활동 상세
- 🎙 외롭다는 말에는 먼저 공감하고, 가까운 동네 모임을 권해요. 온라인 대화가 오프라인 만남으로 이어지도록.

### 안전 장치 (가드레일)
- 🎬 「무릎이 너무 아파요」 → 🎙 몸 상태나 약은 판단하지 않고 의사 선생님께 여쭤보시라고 안내해요.
- 🎬 「다 끝내고 싶어요」 → '109 상담 전화하기' 버튼
- 🎙 위험한 마음이 느껴지면 혼자 두지 않아요. 24시간 자살예방 상담전화 109로 바로 연결해 드려요.

## 7. 마음 건강 · 긴급 도움 — 화면·시연 데이터

> 백엔드 없이 데모에서만 동작해요. 고립 지수는 보고서 공식(활동·대화·마음·이웃 만남·답장 가중합)을 데모 속 실제 활동으로 계산해요.

### 마이페이지 → 마음 건강
- 🎬 '마음 건강' → 이번 주 마음 날씨(맑음·구름 조금·흐림·비) + 고립 지수
- 🎙 숫자 대신 날씨로 보여 드려요. 앱 활동, 대화, 말동무와 나눈 이야기의 마음, 이웃 만남, 답장 빠르기를 함께 살펴 매주 계산해요.
- 🎬 '4주 변화' → 🎙 친구가 생기고 대화가 늘면서 3주 전보다 좋아지고 있어요.
- 🎬 (선택) 말동무에게 「너무 외로워요」를 몇 번 → 다시 마음 건강 → 날씨가 흐려진다
- 🎙 말동무 대화에서 느껴지는 마음도 반영돼요. 위험 단계가 되면 보호자와 담당 복지사에게 알려요.

### 마음 점검 (자가평가)
- 🎬 '기분 점검 (9문항)' → 한 화면에 한 문항, 큰 버튼 네 개
- 🎙 우울(PHQ-9)·불안(GAD-7) 표준 문항을 쉬운 말로 바꿨어요. 결과는 「괜찮아요」처럼 말로 알려 드리고, 진단이 아니라 스스로 살펴보는 점검이에요.
- 🎙 마지막 문항에 위험한 생각이 있다고 답하시면 109 상담 전화를 바로 안내해요.

### 홈 → 긴급 도움
- 🎬 홈 오른쪽 위 '긴급' → 큰 '도움 요청' 버튼 → 「도움을 요청할까요?」 → '알리기' → 「알렸어요」
- 🎙 어느 화면에서든 세 번 안에 도움을 부를 수 있어요. 잘못 누르지 않도록 한 번만 확인하고, 아들과 담당 복지사에게 바로 알려요.
- 🎙 바로 전화하기 — 보호자, 119, 109 마음 상담.

### 보호자 연결
- 🎬 마이페이지 → '보호자 연결' → 등록된 두 분, '보호자 추가'
- 🎙 보호자는 세 분까지. 전화번호는 가려서 보여 드려요.
- 🎬 (선택) 말동무 위기 안내에서 '보호자에게 알리기'

## 8. 가까운 복지시설 · 두뇌 운동 — 화면·시연 데이터

> 백엔드 없이 데모에서만 동작해요. 복지시설은 공공데이터포털 노인복지시설 형식을 본뜬 가상 시설이에요.

### 지역생활 → 가까운 복지관·경로당
- 🎬 '지역생활' 맨 위 '가까운 복지관·경로당' → 가까운 순 목록, 복지관·경로당·시니어센터로 나눠 보기
- 🎙 공공데이터의 전국 노인복지시설 정보를 내 동네 가까운 순으로 보여 드려요.
- 🎬 '○○노인종합복지관' → 여는 시간·전화, 프로그램(남은 자리), 모임 공간 빌리기 → '전화로 신청하기'
- 🎙 앱에서 만난 이웃과 복지관 사랑방을 빌려 모일 수도 있어요. 온라인 친구가 동네 모임으로 이어지도록.

### 홈 → 오늘의 두뇌 운동
- 🎬 홈 아래 '오늘의 두뇌 운동'(「3일 이어 했어요」) → 이번 주 한 날 표시, 짝 맞추기·셈하기
- 🎙 하루 몇 분, 기억력과 집중력을 깨우는 쉬운 놀이예요. 며칠째 이어 하는지 보여 드려 꾸준히 하시도록 도와요.
- 🎬 '셈하기' → 큰 숫자 버튼으로 다섯 문제 → 「모두 맞혔어요!」 → 「4일째 이어 하고 있어요」
- 🎬 (선택) '짝 맞추기' → 카드 두 장씩 뒤집기 — 그림 옆에 이름이 같이 나와요

## 9. 알림함 · 회원 탈퇴 · 운영자 화면 — 화면·시연 데이터

- 🎙 휴대폰 알림을 놓쳐도 여기 다 모여 있어요. 누르면 바로 그 화면으로 가요.
