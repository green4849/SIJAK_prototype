# 시연 영상 대본 — 시니어 6080 위피 '시작'

화면에서 걷어낸 설명 문장(A18)을 버리지 않고 **화면 순서대로** 모은 대본이다.
앱 화면은 큰 글씨·적은 글씨로 두고, 설명은 영상 내레이션·자막으로 전한다.

- **둘러보기 링크**: https://green4849.github.io/SIJAK_prototype/?tour (김시작님 계정, 친구·대화·포인트가 채워진 상태)
- **처음부터 링크**: https://green4849.github.io/SIJAK_prototype/ (가입 과정을 보여 줄 때)
- 표기: 🎬 화면에서 할 동작 · 🎙 내레이션(자막) · 「」 화면에 있던 원래 문구

---

## 1. 시작하기 (가입)

### ① 시작 화면
- 🎬 앱을 연다 → 로고와 '시작하기' 버튼
- 🎙 「같은 동네, 좋은 이웃과 더 따뜻한 일상으로」 — 시니어의 작지만 큰 변화, '시작'입니다.

### ② 로그인 · 본인인증
- 🎬 '시작하기' → 인증 방법 세 가지
- 🎙 「안전한 이용을 위해 본인인증을 진행해 주세요.」 '시작'은 실명으로 확인된 이웃만 만나는 서비스예요.
- 🎙 휴대폰 인증은 「가장 간편해요」. 신분증 인증(「주민등록증·운전면허증」)은 준비 중이고,
  혼자 하기 어려운 분은 '도움받기'로 「가족·직원이 도와드려요」.
- 🎬 (선택) '신분증 인증' → 🎙 「휴대폰이 본인 명의가 아니라면 '도움받기'를 눌러 주세요.」
- 🎬 (선택) '도움받기' → 🎙 「혼자 하기 어려우시면 가까운 분께 부탁해 보세요.」 옆에서 함께 인증하면 돼요.

### 휴대폰 인증 · 인증번호
- 🎬 이름·태어난 날·전화번호 입력 → '인증번호 받기'
- 🎙 「처음 한 번만 확인하면 다음부터는 자동으로 들어가요.」
- 🎙 태어난 해는 네 자리로(「예: 1955」), 전화번호는 「숫자만 적으면 돼요」 — 줄표는 저절로 들어가요.
- 🎬 인증번호 입력 → 🎙 「문자로 받은 숫자 6개를 적어 주세요.」

### 가입 — 지역 · 관심사
- 🎬 지역과 관심사 고르기
- 🎙 「잘 맞는 친구를 찾도록 두 가지만 알려 주세요.」 관심사는 「5개까지 고를 수 있어요」 — 이걸로 친구를 추천하고 대화 주제도 골라 드려요.

### ⑧ 안전 안내 (가입 직후)
- 🎬 네 가지 안전 카드 → '알겠어요, 시작할게요'
- 🎙 「안심하고 이용하세요.」
  - 실명 인증 — 「본인 확인을 마친 분들만 이용해요.」
  - 위험한 대화 자동 감지 — 「돈·계좌·비밀번호를 묻는 대화는 바로 알려 드려요.」
  - 신고 및 차단 — 「불편한 분은 바로 신고하고 차단할 수 있어요.」
  - 개인정보 보호 — 「전화번호는 암호화해서 보관하고, 다른 분께 보이지 않아요.」

## 2. 홈 · 친구 찾기

### ③ 홈
- 🎬 홈 화면 — 큰 카드 세 개, 오른쪽 위 포인트, 아래 '첫 친구 3명 사귀기'
- 🎙 친구 찾기에서는 「같은 동네 좋은 이웃을 만나보세요」, 대화하기에서는 「새로운 이웃과 이야기를 나눠요」,
  지역생활에서는 「우리 동네 다양한 활동을 함께해요」. 무엇이든 세 번 안에 닿도록 만들었어요.
- 🎙 첫 친구 미션: 「친구와 서로 한 번 이상 이야기를 나누면 1명으로 세어요」 — 아무나 추가하는 게 아니라
  진짜 대화를 나눈 친구 3명이 되면 500포인트를 드려요. (진행 표시 「1명 완료 · 2명 남았어요」)

### ④ 동네 친구 찾기 — 추천 · 평가
- 🎬 '친구' 탭 → 추천 친구 목록
- 🎙 「우리 동네의 좋은 이웃을 만나보세요.」
- 🎬 김영희님 카드에서 '만나보고 싶어요' 누르기 → +10P 알림
- 🎙 별점 대신 말로 된 버튼 세 개로 평가해요. 「이웃을 평가하면 +10P · 오늘 ○번 남았어요」 — 하루 다섯 번까지.
  「평가는 상대에게 알려지지 않아요」. 평가는 다음 추천에 반영되고, '잘 안 맞아요'를 누른 이웃은 다시 보이지 않아요.
  (다섯 번을 다 쓰면: 「오늘 평가 포인트는 다 받았어요. 평가는 계속 추천에 반영돼요」)
- 🎬 '같은 동네' 탭 → '내 위치 사용하기'
- 🎙 내 위치는 「동네 정도(약 1km)」로만 저장해요. 「정확한 주소는 저장하지 않고, 다른 분께도 보이지 않아요.」

### 친구 신청 · 포인트
- 🎬 '친구 신청 · 30P' 몇 번 누르기 → 포인트가 모자라면 안내 창
- 🎙 첫 신청은 무료, 받은 신청을 수락하는 건 언제나 무료예요. 같은 분께 다시 신청해도 한 번만 내요.
- 🎙 포인트가 모자라면 결제부터 권하지 않고 '무료로 모으기'를 먼저 보여 드려요 —
  「추천 친구 평가 · 봉사모임 · 첫 친구 미션」. 구독하면 「매달 포인트가 들어와요」.

## 3. 대화 · 안전

### 대화 목록 (대화가 없을 때)
- 🎬 대화 목록 → 노부부 그림과 '아직 대화가 없어요'
- 🎙 「친구가 된 이웃과 이야기를 나눌 수 있어요.」 — 낯선 사람이 먼저 말을 걸 수 없게, 친구가 된 뒤에만 대화해요.

### ⑤ 1:1 대화 — 대화 주제 추천
- 🎬 이순자님 대화방 → '대화 주제 추천' 펼치기 → 문구 하나 누르기 → 입력칸에 들어감
- 🎙 첫마디가 제일 어렵죠. 「무슨 말을 할지 고민되세요?」 「두 분이 함께 좋아하는 '산책·등산' 이야기예요.」
  「누르면 입력칸에 들어가요.」 — 자동으로 보내지 않고, 고쳐서 직접 보내요.
- 🎬 마이크 버튼으로 음성 메시지 → 🎙 글자가 어려우면 말로 보내요.

### 안전 — 위험 대화 경고 · 신고
- 🎬 정덕수님 대화방 → 송금 이야기에 빨간 경고 → '신고하기'
- 🎙 돈·송금 이야기가 나오면 받는 사람 화면에 바로 경고가 떠요.
- 🎬 신고 이유 고르고 '신고하고 차단하기' → 🎙 「신고하면 이 분과는 더 이상 대화할 수 없어요.」

---

## 4. 지역생활 · 봉사

### ⑥ 지역생활
- 🎬 '지역생활' 탭 → '봉사' 분류
- 🎙 「경기도에서 함께하는 다양한 활동을 만나보세요.」(내 지역 이름이 들어가요) 복지관과 함께하는 봉사모임에 참여하면 포인트를 드려요.

### ⑦ 활동 상세 · 신청
- 🎬 '어르신 도시락 나눔' → '신청하기' → +100P 알림
- 🎙 활동마다 한 줄 소개가 있어요 — 예: 「복지관과 함께 이웃에게 도시락을 전해요」,
  「함께 걸으며 건강도 챙기고 좋은 이웃도 만나요!」. 정원은 「선착순」이에요.
- 🎙 봉사는 참여하면 +100P, 「신청을 취소하면 돌려드려요」.

---

## 5. 마이페이지

### ⑨ 내 포인트
- 🎬 마이페이지 → '내 포인트'
- 🎙 모으는 방법: 추천 친구 평가(「하루 5번까지」), 봉사모임 참여(「복지관과 함께하는 지역생활 봉사」),
  첫 친구 3명 사귀기(「서로 이야기를 나눈 친구 3명」). 쓰는 곳: 친구 신청(「첫 신청은 무료예요」 · 「같은 분께 다시 신청해도 한 번만」),
  받은 친구 신청 수락은 「언제나 무료예요」.
- 🎙 체험단 기간에는 「체험 기간이에요 · ○월 ○일까지 친구 신청에 포인트를 쓰지 않아요」.

### 알림 설정
- 🎬 마이페이지 → '알림 설정' → 받는 시간 바꾸기
- 🎙 「오늘의 추천 친구 알림」 — 「새 동네 이웃이 추천되면 알려 드려요」. 알림이 너무 잦으면 오히려 앱을 지우게 돼서
  하루 두 번까지만, 원하는 시간에 받아요. (두 개를 고른 상태에서: 「다른 시간을 고르려면 하나를 먼저 꺼 주세요」)
  밤 9시부터 아침 8시까지는 보내지 않아요.

### 화면 설정
- 🎬 '글자 크기 · 화면 설정' → '아주 크게', '선명한 화면'
- 🎙 글자 크기는 네 단계 — 「누르는 즉시 바뀌어요」. 「'선명한 화면'은 검은 바탕에 밝은 글씨예요」.
  진동은 「저장·신청 같은 일을 마치면 짧게 진동해요 (지원하는 휴대폰만)」. 「이 설정은 지금 쓰시는 휴대폰에만 저장돼요.」

### 내 프로필
- 🎬 '내 프로필 관리' → 한 줄 소개
- 🎙 한 줄 소개는 이웃에게 보여요 — 「예: 산책과 옛날 노래를 좋아해요」.

| 지웠다 | 남겼다 |
|---|---|
| 제목만 봐도 아는 부제·카드 설명, "누르는 즉시" 같은 사용 안내, 모으기·쓰기 줄의 보조 설명 | 이름·나이·일정·장소·포인트 숫자, 위험 대화 경고, 위치 저장 범위(한 줄), 도움말·홈 화면 놓기 방법(설명이 곧 내용인 화면) |
