# UX·기능 변경 기록

보고서·발표 자료를 쓸 때 바로 옮겨 쓸 수 있도록 **화면에서 무엇이, 왜 바뀌었는지**만 모은 기록이다.
코드·구현 방식은 각 작업 파일(`docs/tasks/`)에, 시연 내레이션은 `docs/demo-script.md` 에 있다.

- 형식: 바뀐 화면 → 전 / 후 → 왜 → 기대 효과
- 새 항목은 위에 추가 (최신순)

---

## 2026-10-14

### 1. 시작 화면 다듬기 — A22

전후 사진·항목별 이유·폴리싱 체크리스트는 `docs/design/A22-welcome-before-after.md`.

| | 내용 |
|---|---|
| **화면** | ① 시작 화면 (앱을 처음 열면 나오는 화면) |
| **전** | 위쪽에 로고·슬로건, 가운데가 크게 비고, 언덕 아래에 화면 폭을 채운 '시작하기' 막대. 정지된 그림이고, 글씨 크기는 가입 후 화면 설정에서만 바꿀 수 있었다 |
| **후** | 처음 열면 새싹이 자라고 두 잎이 펼쳐지는 2초 연출. 새싹·'시작'·슬로건·둥근 '시작하기' 버튼이 가운데 한 묶음, 언덕은 맨 아래 배경. 오른쪽 위 '가가'로 바로 글씨를 키울 수 있다. 슬로건은 '**시**니어의 **작**지만'의 두 글자만 초록 |
| **왜** | 첫 화면이 서비스의 의미(이웃과의 만남)를 전하지 못했고, 빈 가운데와 따로 노는 버튼이 어색했다. 글씨가 작아 힘든 가입 단계에서 정작 글씨를 키울 방법이 없었다 |
| **기대 효과** | 로고 의미가 설명 없이 전달되고 시연 첫 장면이 기억에 남음, 가입 전체를 큰 글씨로 진행 가능, 화면 위계(로고가 주인공)가 분명해짐 |

- 연출은 처음 열 때만 온전히, 이후엔 0.5초. 버튼은 연출 중에도 누를 수 있고, 기기에서 '움직임 줄이기'를 켰으면 연출 없음
- '가가'는 화면 설정의 글자 크기와 같은 값 (누르면 '더 크게' ↔ 보통). 화면 읽기 기능에선 "글씨 크게"로 읽힘
- '시작하기'는 작아졌지만 높이(터치 영역 56)는 그대로, 슬로건 회갈색도 대비 7:1 유지

## 2026-10-13

### 1. 사는 곳은 '위치 정보 수집 동의'로 정한다 (가입) — A21

| | 내용 |
|---|---|
| **화면** | 가입 마무리 (이름 인사 아래) |
| **전** | 시·도 17개를 큰 버튼으로 늘어놓고 하나를 고르게 했다 |
| **후** | **위치 정보 수집 동의** 한 줄만 있다. 동의하면 그 자리에서 위치를 읽어 「경기도 수원시 영통구 매탄동」처럼 동네까지 보여 준다 |
| **왜** | 17개 버튼은 화면을 길게 만들고, 어르신이 자기 시·도 이름을 목록에서 찾아 읽어야 했다. 동네 기반 서비스(당근 등)에서 익숙한 '위치 동의 한 번'으로 대신한다 |
| **기대 효과** | 가입 단계 축소(고르기 → 동의 한 번), 잘못 고를 일 없음, 같은 동네 이웃 추천의 정확도 상승 |

- 저장 범위는 동의 줄에 한 줄로 안내: 「동네(약 1km)까지만 저장해요」 — 정확한 주소는 저장하지 않는다
- 동의한 위치는 **친구 탭 '같은 동네'에도 그대로 쓰인다** → 가입한 분에게는 위치를 두 번 묻지 않는다
- 위치 권한을 거부하거나 위치를 못 읽으면 동의가 꺼지고 이유를 안내한다 (「위치 사용을 허락하지 않으셨어요. 휴대폰 설정에서 허용하면 다시 할 수 있어요.」)
- **정책 결정**: 위치 동의는 가입 필수다. 사는 곳을 정할 다른 방법(직접 고르기)을 두지 않는다
- 프로필 수정 화면에서 '사는 곳' 항목을 뺐다 (사는 곳은 마이페이지에 표시)

### 2. 마이페이지 '위치 다시 확인' — A21

| | 내용 |
|---|---|
| **화면** | 마이페이지 → 내 활동 메뉴 (내 프로필 관리 바로 아래) |
| **전** | 사는 곳을 바꾸려면 프로필 수정에서 시·도를 다시 골라야 했다 |
| **후** | **위치 다시 확인** 한 줄 (오른쪽에 지금 사는 곳 표시). 누르면 지금 위치로 사는 곳과 '같은 동네' 위치를 함께 새로 고친다 |
| **왜** | 사는 곳을 위치 동의로만 정하게 되면서, 이사한 경우 바꿀 길이 필요했다. 누르는 것이 곧 위치 동의 재확인이다 |
| **기대 효과** | 이사·장기 거주지 변경에도 동네 이웃 추천이 맞게 유지 |

- 결과는 짧은 알림으로: 「사는 곳을 부산광역시로 바꿨어요」 / 그대로면 「지금도 경기도예요」

### 3. 지역생활 활동에 실제 사진 — A20

| | 내용 |
|---|---|
| **화면** | ⑥ 지역생활 목록 썸네일, ⑦ 활동 상세 상단 |
| **전** | 활동 종류별 아이콘 + 색 (걷기 = 발자국, 노래 교실 = 음표 …) |
| **후** | 활동 종류마다 어울리는 실사 사진 (함께 걷는 사람들, 악보 보며 노래하는 어르신들, 상자 텃밭 상추, 도시락 포장 봉사 등) |
| **왜** | 아이콘만으로는 실제 복지관·주민센터 프로그램이라는 느낌이 약했다. 사진이 있어야 "가 보고 싶다"는 마음이 든다 |
| **기대 효과** | 활동 신청 의향 상승, 시연 화면의 현실감 |

- 사진을 못 불러오면(인터넷 끊김 등) 예전 아이콘으로 자동 대체 → 빈 칸이 보이지 않는다
- 실제 서비스에서는 복지관·주민센터가 올린 프로그램 사진으로 바꾼다 (프로토타입은 무료 사진 사이트 이미지)

### 4. 친근한 일러스트 반영 + 배너 잘림 수정 — A19

| | 내용 |
|---|---|
| **화면** | ① 시작, ③ 홈 인사 아래 풍경 띠, ⑥ 봉사 탭 풍경 띠, ⑧ 안전 안내, 포인트·알림·빈 목록, 모든 아바타 |
| **전** | 이름 글자 아바타, 그림 없는 화면 (글씨 줄이기 이후 차갑게 느껴짐) |
| **후** | 처음 시안 분위기의 인물 일러스트(웃는 얼굴 아바타, 손 흔드는 이웃·노부부 장면) |
| **왜** | 읽기 쉽게 다듬는 과정(A12~A18)에서 처음 시안의 따뜻함이 빠졌다 |

- **배너 잘림 수정**: PC·태블릿처럼 넓은 화면에서 홈·봉사 배너의 인물 머리가 잘렸다 → 하늘·언덕은 화면 폭만큼 늘리고 인물은 원래 비율로 가운데 배치해 어떤 화면에서도 잘리지 않게 했다
- 참고: 일러스트 작업은 머지 대상 브랜치가 어긋나 한동안 데모에 반영되지 않았다가 이날 반영됐다

### 5. 대화는 탭이 아니라 홈 카드로 들어간다 (안내용 정리)

새로 바뀐 것은 아니고, 위치를 자주 묻는 부분이라 기록해 둔다.
- 하단 탭은 홈·친구·지역생활·마이페이지 4개다. 대화는 **홈의 '대화하기' 카드** 또는 **친구 카드의 '대화하기' 버튼**으로 들어간다
- 안 읽은 메시지 수는 하단 탭 '홈'에 배지로 보인다
- 대화 화면에서는 하단 메뉴가 사라지고 '뒤로'로 나온다 (대화에 집중)
