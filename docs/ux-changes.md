| | 내용 |

| **전** | 동의 단계 없이 본인 확인 → 좋아하는 것 → 사는 동네로 바로 가입. 실명·전화번호·위치·마음 건강 결과를 모으면서 동의 기록이 없었다 |

| **왜** | 실서비스 전 필수(개인정보 보호법·위치정보법). 마음 건강 점검(우울·불안) 결과는 건강 정보 = 민감정보라 따로 동의를 받아야 한다 |
| **기대 효과** | 시범 운영을 법적으로 시작할 수 있는 바탕. 무엇을 왜 모으는지 어르신이 읽을 수 있는 말로 먼저 보여 준다 |

- 필수 동의는 철회 대신 탈퇴로 안내한다 (서비스를 쓸 수 없으므로)

- 언제 어느 버전에 동의·거부·철회했는지 서버에 쌓아 둔다 (지우거나 고치지 않음)

### 6. 성향조사 — 잘 맞는 이웃을 먼저, 왜 맞는지 말로

| | 내용 |
|---|---|
| **화면** | 친구 찾기(추천 친구 탭·카드), 새 화면 '성향조사', 가입·프로필의 '좋아하는 것' |
| **전** | 추천 순서는 겹치는 관심사 수와 평가로만 정했고, 관심사가 안 겹치면 「같은 동네 이웃이라 추천했어요」 말고는 이유가 없었다. '좋아하는 것'은 13개(노래·음악, 바둑·장기, TV·드라마, 뜨개질, 종교 활동, 옛날이야기 등). 다른 시·도 이웃도 추천에 섞였다 |
| **후** | 추천 친구 탭에 처음 들어가면 「나와 잘 맞는 동네 친구 찾기」 시작 화면(시작이 말풍선, '다음에 하기'). 8문항 — 좋아하는 활동, 하고 싶은 일, 만날 곳, 편한 시간, 만나는 횟수, 대화 습관, 편한 친구, 나를 표현하는 단어 — 을 한 화면에 하나씩. 끝나면 「성향조사를 마쳤어요!」 → '추천 친구 만나보기'. 카드에는 점수 대신 「잘 맞아요」와 이유(「둘 다 평일 오전이 편해요」·「바라시던 '조용하고 차분한' 분이에요」·「둘 다 공원에서 만나고 싶어 해요」). 추천은 5km 안(위치가 없으면 같은 시·도) 이웃만. '좋아하는 것'은 성향조사 Q1과 같은 10개(산책·등산, 영화·공연, 요리·맛집 탐방, 낚시, 독서·문화생활, 경제·재테크, 여행, 운동·건강관리, 원예·식물 가꾸기, 봉사활동) — 새 그림 셋(영화·공연, 경제·재테크, 봉사활동) |
| **왜** | "100% 나랑 잘 맞는 사람"은 약속할 수 없다. 대신 무엇이 맞는지 보여 주면 먼저 말을 걸 이유가 생기고, 숫자(87점)는 '완벽한 사람'처럼 읽히거나 낮은 점수가 상처가 될 수 있다 |
| **기대 효과** | 추천 카드만 보고도 "이분은 나처럼 아침에 공원 걷는 걸 좋아하는구나"를 알아 첫 인사가 쉬워진다 |

### 5. 마음 건강 살펴보기(WHO-5) — 가입할 때 처음, 그 뒤 4주마다

| | 내용 |
|---|---|
| **화면** | 가입 직후(보안 안내 다음), 홈, 마이페이지 → 마음 건강, 새 화면 '마음 건강 살펴보기'·'나의 이전 결과', 알림함 |
| **전** | 마음 점검은 기분 점검(PHQ-9)·걱정 점검(GAD-7) 두 가지뿐이었고, 둘 다 '힘든 정도'를 묻는 검사라 좋아지는 흐름을 보여 주기 어려웠다. 언제 다시 하면 되는지 알려 주는 곳이 없었다 |
| **후** | 세계보건기구 웰빙 지수(WHO-5) 다섯 문항을 더했다. 보기 여섯 개(전혀 없음~항상)에 숫자 동그라미를 함께 붙이고, 고른 답을 확인한 뒤 '다음'을 누른다(이전으로 가도 고른 답이 남음). 결과는 「이전 결과 60점 · 이번 결과 80점 · 이전보다 20점 높아졌어요」처럼 지난번과 나란히, 단계는 말로(66~100 「마음이 건강한 편이에요」, 51~65 「보통이에요」, 0~50 「마음이 지쳐 있어요」). 이어서 해 볼 일 카드 세 장 — 좋아졌으면 「친구와 안부 나누기·가볍게 산책하기·관심 있는 모임 나가기」, 낮아졌으면 「고마운 분과 대화하기·가볍게 몸 움직이기·좋아하는 일 하며 쉬기」와 전문가 상담 안내(디자인 문구를 줄임 — 글자 4단계 320px에서 '움직임으/로'처럼 단어 중간이 끊겼다). 28점 이하이면 109 상담 전화 버튼. '나의 이전 결과'에 점수 선 그래프와 날짜별 목록. 가입하면 보안 안내 다음에 바로 시작 화면이 나오고 '나중에 할게요'로 미룰 수 있다. 미루거나 4주가 지나면 홈에 「마음 건강 살펴볼 때예요」 카드, 4주가 지나면 알림함에도 한 번 |
| **왜** | 웰빙 지수는 높을수록 좋은 점수라 '나아지고 있다'를 보여 주기 좋고, 4주 간격으로 같은 질문을 하면 변화를 볼 수 있다. 마음 건강 정보라 가입을 막지 않도록 미룰 수 있게 했다. 점수는 본인에게만 보이고 친구 추천에는 쓰지 않는다 |
| **기대 효과** | 가입 첫날 기준 점수가 생기고, 4주마다 내 마음의 변화를 숫자와 말로 확인한다. 점수가 낮을 때 할 일과 도움받을 곳으로 바로 이어진다 |

| **후** | 처음 열면 새싹이 자라고 두 잎이 펼쳐지는 2초 연출. 새싹·'시작'·슬로건·둥근 '시작하기' 버튼이 가운데 한 묶음, 언덕은 맨 아래 배경. 오른쪽 위 '가가'로 바로 글씨를 키울 수 있다. 슬로건은 '**시**니어의 **작**지만'의 두 글자만 초록 |
| **왜** | 첫 화면이 서비스의 의미(이웃과의 만남)를 전하지 못했고, 빈 가운데와 따로 노는 버튼이 어색했다. 글씨가 작아 힘든 가입 단계에서 정작 글씨를 키울 방법이 없었다 |
| **기대 효과** | 로고 의미가 설명 없이 전달되고 시연 첫 장면이 기억에 남음, 가입 전체를 큰 글씨로 진행 가능, 화면 위계(로고가 주인공)가 분명해짐 |

- 연출은 열 때마다 같다(약 2초. 처음엔 두 번째부터 짧게 했다가, 시연에서 매번 보이도록 바꿈). 버튼은 연출 중에도 누를 수 있고, 기기에서 '움직임 줄이기'를 켰으면 연출 없음
- '가가'는 화면 설정의 글자 크기와 같은 값 (누르면 '더 크게' ↔ 보통). 화면 읽기 기능에선 "글씨 크게"로 읽힘
- '시작하기'는 작아졌지만 높이(터치 영역 56)는 그대로, 슬로건 회갈색도 대비 7:1 유지

- 프로필 수정 화면에서 '사는 곳' 항목을 뺐다 (사는 곳은 마이페이지에 표시)
