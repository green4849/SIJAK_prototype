# A15. 화면별 세부 배치 (디자인 리뷰 4단계)

| 영역 | 크기 | 우선 | 상태 | 브랜치 |
|---|---|---|---|---|
| 폴리싱 | M | P1 | ⬜ 대기 | `polish/A15-screen-layout` |

## 왜
[디자인 리뷰 v1](../design/review-v1.md) 화면별 ②~⑨ 항목 중 A12~A14에서 해결되지 않은 것. 리뷰는 시안 기준이므로 구현 화면에 해당하는 것만 반영한다.

## 손댈 곳
FriendsPage(카드), ChatRoomView·MessageList(말풍선·입력줄), ActivitiesPage·ActivityDetail, SafetyPage, MyPage

## 완료 기준
- [ ] ④ 친구 카드: 이름(주)·나이(보조) 같은 기준선, 소개 글 본문 크기, 이름→소개→버튼 간격 일정, 신청 버튼이 소개보다 지배적이지 않게, 상단 설명과 거리 조건 분리
- [ ] ⑤ 대화: 말풍선 최대 폭 75–80%, 내부 여백 일정, 시간 위치 통일, 날짜 표시는 작은 중립색, 같은 사람 연속 메시지는 가깝게, 입력줄(입력칸·말하기 버튼) 높이·중심 맞춤, 안내 글자 크기 확보
- [ ] ⑥ 지역생활: 필터 간격·여백 통일, 제목·일정·장소 위계, 긴 활동명 두 줄 대응
- [ ] ⑦ 활동 상세: 제목·소개 강조 차이, 참여 인원 숫자 위계, 관심 표시 선택 상태(위치·크기 고정), 하단 신청 영역에 본문 가리지 않음
- [ ] ⑧ 보안 안내: 제목·보조 설명 위계, 카드 높이는 내용대로
- [ ] ⑨ 마이페이지: 프로필 이미지 축소·텍스트 폭 확보, 프로필/메뉴 구분, 개수 표시 오른쪽 정렬, 로그아웃 강조 절제
- [ ] 긴 내용(긴 이름·활동명·장소·소개·채팅 문장) 데모 데이터로 확인
- [ ] 수정 후 점검(리뷰 마지막 절): 실제 크기·큰 글자·다른 폭·긴 내용 캡처 비교
