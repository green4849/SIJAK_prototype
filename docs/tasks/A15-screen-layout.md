# A15. 화면별 세부 배치 (디자인 리뷰 4단계)

| 영역 | 크기 | 우선 | 상태 | 브랜치 |
|---|---|---|---|---|
| 폴리싱 | M | P1 | ✅ 완료 | `polish/A15-screen-layout` |

## 왜
[디자인 리뷰 v1](../design/review-v1.md) 화면별 ②~⑨ 항목 중 A12~A14에서 해결되지 않은 것. 리뷰는 시안 기준이므로 구현 화면에 해당하는 것만 반영한다.

## 손댈 곳
FriendsPage(카드), ChatRoomView·MessageList(말풍선·입력줄), ActivitiesPage·ActivityDetail, SafetyPage, MyPage

## 완료 기준
- [x] ④ 친구 카드: 이름(주)·나이(보조) 같은 기준선, 소개 글 본문 크기, 이름→소개→버튼 간격 일정, 신청 버튼이 소개보다 지배적이지 않게, 상단 설명과 거리 조건 분리
- [x] ⑤ 대화: 말풍선 최대 폭 75–80%, 내부 여백 일정, 시간 위치 통일, 날짜 표시는 작은 중립색, 같은 사람 연속 메시지는 가깝게, 입력줄(입력칸·말하기 버튼) 높이·중심 맞춤, 안내 글자 크기 확보
- [x] ⑥ 지역생활: 필터 간격·여백 통일, 제목·일정·장소 위계, 긴 활동명 두 줄 대응
- [x] ⑦ 활동 상세: 제목·소개 강조 차이, 참여 인원 숫자 위계, 관심 표시 선택 상태(위치·크기 고정), 하단 신청 영역에 본문 가리지 않음
- [x] ⑧ 보안 안내: 제목·보조 설명 위계, 카드 높이는 내용대로
- [x] ⑨ 마이페이지: 프로필 이미지 축소·텍스트 폭 확보, 프로필/메뉴 구분, 개수 표시 오른쪽 정렬, 로그아웃 강조 절제
- [x] 긴 내용(긴 이름·활동명·장소·소개·채팅 문장) 데모 데이터로 확인
- [x] 수정 후 점검(리뷰 마지막 절): 큰 글자·다른 폭·긴 내용 캡처 비교 — **실제 휴대폰 크기 확인은 A11(사람)로**

## 진행 기록

- ④ 친구 카드: 버튼이 하나면 카드 전체 폭 대신 절반 이상(`:only-child`), 수락/다음에 두 개는 반씩. 소개 글과 이름 사이 간격 고정. (구현 화면에는 '반경 2km' 문구가 없어 거리 조건 분리 항목은 해당 없음)
- ⑤ 대화: 같은 사람이 이어 말하면 간격 8px·아바타 자리만 비움, 말하는 사람이 바뀌거나 날짜가 바뀌면 24px. 말풍선 그림자 제거(흰 면만), 안쪽 여백 12/16, 최대 폭 78%. 날짜 표시 굵기 낮춤. 입력칸 안내 글자 `--color-placeholder`(6.7:1), 입력칸·말하기 버튼 같은 높이
- ⑥ 지역생활: 필터 좌우 여백 24→16 — 390px에서 4개가 한 줄. 목록 카드는 위 정렬(긴 제목 3줄에도 썸네일·제목 시작선 고정), 꺾쇠만 가운데
- ⑦ 활동 상세: 참여 인원 '**9명** 신청 · 정원 12명 (선착순)' — 현재 인원이 먼저 크게. 관심 버튼은 A14에서 위치·크기 고정
- ⑧ 보안 안내: A12(제목·설명 위계)·A13(평평한 정보 카드, 높이는 내용대로)로 해결
- ⑨ 마이페이지: 아바타 72(A14), 로그아웃은 카드 면·그림자 없는 빨간 글자 줄(`MenuList plain`)
- 긴 내용 확인용 시드: 윤기철 소개를 3~4줄로, '스마트폰 활용 교육 (사진 보내기·영상통화 기초반)'·긴 장소 — 데모(`demo/store.ts`, 시드 VERSION 2)와 백엔드 `scripts/seed.py` 같이
- 해당 없음/남김: 대화 '+ 추가 버튼'(구현에 없음), 키보드가 열린 화면은 실제 기기에서 A11 때 확인
