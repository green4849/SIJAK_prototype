## 진행 기록
- 시설 프로그램은 기존 지역생활 활동과 따로 둠 — 연동되면 활동(⑥)으로 합칠지 결정
- 2026-10-14 시연 데이터를 오산시 양산동 기준으로: 양산동 단지 경로당 3곳·오산노인종합복지관·오산시니어클럽 (이름·동네는 실제, 프로그램·전화번호는 시연용 — 실제 기관 번호 아님)
- 2026-10-14 다듬기: 거리는 '걸어서 몇 분'(어르신 걸음 분당 50m, 1.5km 넘으면 km), '지금 열려 있어요 · 17시까지' / '내일 10시에 열어요'(여는 시간 글을 읽어 계산 — 연동 때는 공공데이터의 요일·시각 값 사용), 종류별 그림(경로당 기와집·복지관 하트 간판 건물·시니어클럽 깃발 건물, A19 그림체). 목록의 '프로그램 N개'는 빼고 상세에서 봄
- '전화로 신청하기'는 일반 전화 링크(누르면 전화 앱에 번호가 입력되고, 통화는 한 번 더 눌러야 걸림) — 시연 번호는 실제 기관 번호가 아니니 통화 버튼까지 누르지 않기
