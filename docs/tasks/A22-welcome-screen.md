## 왜
시작 화면은 어르신이 앱을 처음 여는 순간이자 심사·시연에서 가장 먼저 보이는 화면이다.
기존 화면은 정돈돼 있었지만 정지된 그림이라 인상이 약했고, 글씨 크기는 가입한 뒤에야 바꿀 수 있었다.
또 슬로건이 로고와 같은 무게로 보이고, 슬로건과 언덕 사이 가운데가 크게 비어 있었다.
시작하기 버튼은 화면 폭을 꽉 채운 막대가 언덕 아래 따로 놓여 있어, 그림 한 장과 입력 양식 버튼이 위아래로 쌓인 듯 어색했다.

## 바뀐 것 (사용자 관점)

### 1. 새싹이 자라나는 등장 연출
- 처음 앱을 열면 약 2초 동안: 새싹 줄기가 자라고 → **두 잎이 차례로 펼쳐지고** → '시작' 글자가 흐릿함에서 또렷해지고 → 슬로건 → 언덕 위로 노부부가 올라오고 하트가 뜬다 → 시작하기 버튼.
- **두 잎 = 서로 다른 두 사람이 만나는 순간**이라는 의미를 담았다. 로고 의미를 설명 없이 움직임으로 전달한다. (발표·시연 대본에서 이 의미를 한 줄 짚어 주면 좋다)
- 다 나온 뒤에는 잎이 몇 초에 한 번 바람에 숨 쉬듯 아주 살짝 흔들린다. 화면이 살아 있는 느낌을 주되 눈에 거슬리지 않을 만큼만.
- 방향: 화려함보다 절제 — 주인공 움직임 하나(잎 펼침), 짧게, 의미 있게.

### 2. 어르신을 배려한 연출 규칙
- **열 때마다 같은 연출**: 처음엔 '두 번째부터 0.5초로 짧게'였지만, 시연·심사에서 매번 같은 첫인상을 보여 주도록 매번 전체 연출로 바꿨다. 시작 화면은 가입 전에만 보이는 화면이라 실제 사용자가 반복해서 기다릴 일은 거의 없다.
- **기다리게 하지 않음**: '시작하기'와 '가가' 버튼은 연출 중에도 바로 누를 수 있다.
- **'움직임 줄이기'를 켠 기기**에서는 연출 없이 완성된 화면만 보인다 (어지럼·멀미 배려).
- 번쩍이거나 빠르게 깜빡이는 효과는 쓰지 않는다.

### 3. 오른쪽 위 '가가' — 가입 전에도 글씨 크게
- 시작 화면 오른쪽 위에 작은 '가' + 큰 '가' 모양 버튼. 누르면 앱 전체 글씨가 '더 크게' 단계로 커지고, 다시 누르면 보통으로 돌아간다.
- 이유: 어르신은 가입 화면의 글을 읽기 전에 글씨부터 키워야 하는 경우가 많은데, 기존에는 가입 후 마이페이지 → 화면 설정에서만 바꿀 수 있었다.
- 화면 설정의 '글자 크기'와 같은 값이다. 여기서 키우면 설정 화면에도 '더 크게'로 보이고, 설정에서 크게 해 두었으면 이 버튼도 켜진 상태로 보인다.
- 글자 없이 '가가' 모양만 둔다 — 포털·은행 앱에서 글씨 크기 버튼으로 흔히 쓰는 모양이라 알아보기 쉽다. 화면 읽기 기능에서는 "글씨 크게"로 읽힌다. 누르는 영역은 손가락 크기만큼 확보.

### 4. 슬로건 — '시'·'작' 강조
- "**시**니어의 **작**지만 큰 변화" — 슬로건 앞글자가 앱 이름 '시작'이 되는 말장난을 드러냈다.
- '시'·'작' 두 글자만 로고와 같은 초록, 나머지는 굵기를 한 단계 낮추고(보통 굵기) 따뜻한 회갈색으로. 로고 '시작'이 확실한 주인공이 되고 슬로건은 한 발 물러난다.
- 회갈색도 배경과의 대비 7:1을 지킨다(앱 공통 기준). 선명한 화면(고대비)에서는 흰색 + 노랑 강조.

### 5. 화면 배치 — 로고·슬로건·시작하기를 한 묶음으로
- **시작하기 버튼을 슬로건 바로 아래로** 올렸다. 새싹 → '시작' → 슬로건 → 시작하기가 화면 가운데에 한 덩어리로 모이고, 시선이 위에서 아래로 한 줄로 흐른다. "이게 뭔지 보고 → 바로 누르는" 순서.
  - 등장 연출에서도 슬로건 다음에 버튼이 아래에서 올라와 이야기가 끊기지 않는다.
  - 어르신은 한 손으로 들고 다른 손 검지로 누르는 경우가 많아, 화면 가운데 버튼도 누르기 어렵지 않다.
- **버튼은 작고 둥글게**: 화면 폭을 채우던 막대 대신 폭 약 절반의 둥근 버튼 — 양식 제출 버튼이 아니라 "들어오세요" 하는 초대처럼. 높이는 앱 공통 최소 터치 영역(56)을 지키고, 글씨를 키우면 버튼도 같이 넓어진다.
- **묶음을 한 단계 크게**: 새싹, '시작' 글자, 슬로건을 조금씩 키웠다. '시작' 로고 글자는 그림처럼 크기를 고정(글씨 크기 설정과 무관), 슬로건은 설정에 따라 커진다.
- **언덕은 맨 아래 배경으로**: 버튼이 빠진 자리까지 언덕이 내려와 화면 아래 끝에 붙는다. 노부부가 조금 더 크게 보이도록 높이를 늘렸다(더 키우면 양옆 나무가 잘려서 그 직전까지).
- **위치 비율**: 고정 여백이 아니라 위 2 : 아래 1 비율로 나눠, 버튼과 언덕 사이가 크게 비지 않고 휴대폰 높이가 달라도 같은 인상이 나온다. 짧은 화면에서는 언덕이 먼저 줄어든다.

## 이번에 하지 않은 것 (다음 논의)
- **다음 화면으로 이어지는 전환**: '시작하기'를 누르면 새싹이 작아지며 다음 화면 머리로 날아가 붙는 연출. 화면이 '바뀌는' 게 아니라 '이어지는' 느낌. 로그인 화면 구조와 같이 손봐야 해서 따로 진행.

## 완료 기준

- [x] '가가'와 화면 설정의 글자 크기가 같은 값으로 움직임
- [x] 슬로건 대비 7:1, 선명한 화면에서도 읽힘

- [x] typecheck·lint·build, e2e(시작 → 가입 흐름, 화면 캡처, 접근성 스윕의 배치 점검)

## 진행 기록
- 디자인 논의는 움직이는 시안(별도 미리보기)으로 먼저 확인한 뒤 반영
- 슬로건 색: 처음 비교한 세 안 중 '차분하게' 안 (말장난을 더 크게 강조하는 안은 나머지 글자가 연해져 대비가 부족해서 제외)
- '가가'에 처음엔 "글씨 크게" 글자를 붙였다가, 모양만으로 충분해 글자는 뺌
- e2e는 '움직임 줄이기' 기준으로 돌린다 — 캡처·클릭이 연출 타이밍에 흔들리지 않게
- 시작하기 버튼 위치 논의: ① 로고 위 가운데(엄지에서 멀고, 앱이 뭔지 보기 전에 버튼이 먼저 보임 → 제외) ② 버튼 없이 자동으로 넘어가기(화면이 저절로 바뀌면 당황하기 쉬움 → 제외) ③ **로고 아래 가운데** — 빈 공간과 따로 노는 버튼 문제를 함께 해결해서 채택
- 2차 배치 조정(버튼 위치·크기, 묶음 크기, 언덕 높이)도 움직이는 시안으로 확인 후 반영
- 다시 열 때 짧게(0.5초) 보여 주던 규칙을 없앰 — 웹에서 띄울 때 연출이 안 보여 헷갈렸고, 시연에서는 매번 전체 연출이 나오는 편이 낫다는 결정
