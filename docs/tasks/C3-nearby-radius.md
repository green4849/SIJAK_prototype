## 진행 기록

- `find_nearby()` 구현 — 대원거리(haversine), 반경 2km, 가까운 순. 내 위치가 없으면 지금처럼 같은 시·도(거리 없음, 화면은 위치 동의 카드). 내 위치가 있으면 반경 안 이웃 뒤에 위치를 안 알린 같은 시·도 이웃을 거리 없이
- 개인정보: 저장 좌표가 이미 ≈1km 격자(소수점 2자리)인 데다 응답 거리도 **0.5km 단위**로 반올림(0은 0.5) → 여러 번 조회해 상대 위치를 역추적하기 어렵게. `FriendCard.distance_km` 설명을 OpenAPI에 기록
- 화면 표시: '0.5km 이내' / '약 1km' / '약 1.5km' (`FriendCard where()`)
- 데모: 사용자에 좌표 추가(백엔드 시드와 같은 값), '내 위치 사용하기'를 누르면 시연 동네 한가운데(`DEMO_HOME`)에 둠 — 보는 사람이 어디 있든 같은 동네 이웃이 보이게. 같은 규칙을 `demo/rules.ts` 에 사본으로 (시드 VERSION 3)
- '같은 동네/추천' 목록 영역에 이름(aria-label) — 화면 낭독기에서 받은 신청 목록과 구분
- 테스트: 단위 4개(거리·반올림·정렬·위치 없음), 통합 1개(반경 밖·위치 안 알린 사람), e2e `nearby.spec.ts`(위치 동의 → 약 1.5km 순서)
- 다음: 사용자 수가 늘면 PostGIS `ST_DWithin` (B8 N+1 정리와 함께)
