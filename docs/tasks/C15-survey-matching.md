# C15. 성향조사와 추천 적합도

| 영역 | 크기 | 우선 | 상태 | 브랜치 |
|---|---|---|---|---|
| 기능 확장 | M | P1 | ✅ 백엔드·데모·화면 | `feat/recommend-survey` |

## 왜
피드백 "100% 나랑 잘 맞는 사람 매칭이 가능할까?" — 100%는 약속할 수 없으니, 성향을 물어 **잘 맞는 순서로 보여 주고 왜 맞는지를 말로** 알려 준다. 질문지·알고리즘은 사용자가 줬다(2026-11-24).

## 결정 (사용자)
- 가입 '좋아하는 것' 13개 → 성향조사 Q1의 10개로 바꿔 하나로 (가입·프로필·성향조사 Q1이 같은 목록)
- 묻는 때: 저절로 넘기지 않는다(2026-11-27 피드백). 들어가는 길 — 하단 5번째 탭 '성향조사', 추천 친구 위 카드(X로 닫으면 이 기기에서 다시 안 권함), 마이페이지 '성향조사 하기 / 내 취향 수정하기'. 질문 중에도 위쪽 'X'(닫기)로 그만둔다. 이미 했으면 탭은 「성향조사를 이미 마쳤어요」 + 고치기
- 후보: 둘 다 위치가 있으면 5km 안, 아니면 같은 시·도
- 카드에는 점수 숫자 없이 말('잘 맞아요' 70+, '비슷한 점이 많아요' 50+)과 이유만. 점수는 순서에만

## 알고리즘 (`backend/app/domains/friend/survey.py` ↔ `frontend/src/demo/matching.ts`)
점수 = 30H + 10G + 10P + 15T + 10F + 25R, 각 0~1, .5 올림.

| 기호 | 문항 | 계산 (질문지에 없던 세부는 여기서 정함) |
|---|---|---|
| H 취미 | Q1 | 겹친 수 ÷ 둘 중 적게 고른 수 |
| G 목적 | Q2 | 같으면 1, 취미·산책운동·지역모임끼리 0.5, '일상 이야기'와 나머지 0 |
| P 장소 | Q3 | 겹친 수 ÷ 적게 고른 수 |
| T 시간 | Q4 | 한쪽이라도 '시간 상관없음'이면 1, 아니면 겹친 수 ÷ 적게 고른 수 |
| F 빈도 | Q5 | 같으면 1, 한 칸 차이 0.5, 그 밖 0 |
| R 성향 | Q6·Q7·Q8 | (D(A→B)+D(B→A))/2. D = (B의 Q6이 A가 바라는 친구에 맞는 정도 1·0.5·0 + B의 Q8에 바라는 성격 단어가 있으면 1) / 2. '취미를 함께 즐기는 친구'면 D = (H+G)/2 |

- 들어주는 친구 ← 들어주는 편 1 · 비슷하게 0.5 / 경청·배려심·다정함
- 밝고 활발한 친구 ← 먼저 꺼내는 편 1 · 비슷하게 0.5 / 활발함·유머감각·호기심
- 조용하고 차분한 친구 ← 들어주는 편 1 · 비슷하게 0.5 / 차분함·신중함·계획적
- 성향조사를 안 한 쪽이 있으면 G·P·T·F·R = 0 (관심사 H로만 줄 세움, 말·이유 없음)
- 정렬: 내 평가('이런 분 더 보여 주세요' 먼저, '잘 안 맞아요'는 뺌) → 점수 → '더 보여 주세요' 한 분들의 관심사와 겹치는 수 → 가까운 순
- 이유(최대 3): 같은 시간대 → 바라던 친구 모습(D ≥ 0.75) → 같은 장소 → 같은 목적 → 같은 빈도. 공통 취미는 카드의 '같이 좋아해요' 칩이 보여 줌

## 한 것
- 백엔드: `friend_surveys` 테이블, `GET/PUT /friends/survey`(Q1은 프로필 관심사로 저장), 추천 탭을 적합도 순으로, `FriendCard.match_label`·`reasons`. 마이그레이션 `8c2d4e6f1a73` — 관심사 노래·음악·TV·드라마 → 영화·공연, 바둑·뜨개질·종교·옛날이야기는 맞는 항목이 없어 지움
- 관심사 10개: 대화 주제 문구, 그림(영화·공연·경제·재테크·봉사활동 새로), 시드 이웃
- 화면: `/friends/survey` 시작(시작이 말풍선) → 한 화면 한 문항(Q1은 그림 칸, 나머지는 큰 버튼, 이전·다음) → 끝('추천 친구 만나보기'·'내 취향 수정하기'). `?edit` 은 1번부터
- 시연: 둘러보기 계정은 안 한 상태라 친구 탭에 처음 가면 시작 화면. 이웃 6명은 답이 있고 최말순님만 없음
