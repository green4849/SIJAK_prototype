# A13. 색 역할·카드 표현 통일 (디자인 리뷰 2단계)

| 영역 | 크기 | 우선 | 상태 | 브랜치 |
|---|---|---|---|---|
| 폴리싱 | M | P1 | ⬜ 대기 | `polish/A13-color-cards` |

## 왜
[디자인 리뷰 v1](../design/review-v1.md) 공통 8~13·19·20, ②-2, ③-1·6, ⑧-2·3. 홈·보안 안내·로그인의 큰 파스텔 색면이 모두 주요 버튼처럼 보이고, 카드마다 그림자·배경·테두리가 섞여 있다.

## 손댈 곳
tokens(색 역할·모서리·카드 경계), `shared/ui/ActionCard`·`Button`·`SegmentTabs`, HomePage·SafetyPage·LoginPage, BottomNav 선택 표시

## 완료 기준
- [ ] 색 역할 고정: 녹색=주요 행동·선택, 중립=정보, 빨강=주의(신고·차단·로그아웃). 토큰 주석에 명시
- [ ] 홈 메뉴·보안 안내 카드: 흰(중립) 카드 + 작은 아이콘 배경에만 포인트 색
- [ ] 로그인 3선택지 위계: 휴대폰 인증=녹색 주요, 신분증=중립 보조, 도움받기=더 낮은 강조
- [ ] 카드 경계는 한 가지(얇은 테두리 또는 약한 그림자)로 통일, 안내 카드는 버튼처럼 보이지 않게
- [ ] 모서리 규칙: 카드 / 버튼 / 필터(알약) 각각 하나의 반경
- [ ] 선택·눌림·비활성 상태 공통 규칙 (색·테두리 변화) — 버튼·탭·필터·메뉴
- [ ] 하단 메뉴 선택 표시: 녹색 아이콘·글자 + 작은 배경
- [ ] 바뀐 색 조합 대비 재확인 (본문 7:1 유지 목표, 최소 4.5:1), 고대비 모드 유지
