# A13. 색 역할·카드 표현 통일 (디자인 리뷰 2단계)

| 영역 | 크기 | 우선 | 상태 | 브랜치 |
|---|---|---|---|---|
| 폴리싱 | M | P1 | ✅ 완료 | `polish/A13-color-cards` |

## 왜
[디자인 리뷰 v1](../design/review-v1.md) 공통 8~13·19·20, ②-2, ③-1·6, ⑧-2·3. 홈·보안 안내·로그인의 큰 파스텔 색면이 모두 주요 버튼처럼 보이고, 카드마다 그림자·배경·테두리가 섞여 있다.

## 손댈 곳
tokens(색 역할·모서리·카드 경계), `shared/ui/ActionCard`·`Button`·`SegmentTabs`, HomePage·SafetyPage·LoginPage, BottomNav 선택 표시

## 완료 기준
- [x] 색 역할 고정: 녹색=주요 행동·선택, 중립=정보, 빨강=주의(신고·차단·로그아웃). 토큰 주석에 명시
- [x] 홈 메뉴·보안 안내 카드: 흰(중립) 카드 + 작은 아이콘 배경에만 포인트 색
- [x] 로그인 3선택지 위계: 휴대폰 인증=녹색 주요, 신분증=중립 보조, 도움받기=더 낮은 강조
- [x] 카드 경계는 한 가지(얇은 테두리 또는 약한 그림자)로 통일, 안내 카드는 버튼처럼 보이지 않게
- [x] 모서리 규칙: 카드 / 버튼 / 필터(알약) 각각 하나의 반경
- [x] 선택·눌림·비활성 상태 공통 규칙 (색·테두리 변화) — 버튼·탭·필터·메뉴
- [x] 하단 메뉴 선택 표시: 녹색 아이콘·글자 + 작은 배경
- [x] 바뀐 색 조합 대비 재확인 (본문 7:1 유지 목표, 최소 4.5:1), 고대비 모드 유지

## 진행 기록

- 색 역할을 `tokens.css` 주석으로 고정: 녹색=주요 행동·선택, 중립=정보·보조, 빨강=주의만, 파스텔=작은 아이콘 배경·아바타·썸네일에만
- `ActionCard` 를 '강조 단계(variant)'와 '포인트 색(accent)'으로 분리 — primary(녹색 면)/default(흰 카드+그림자)/subtle(면 없음). 아이콘은 48px 원 안에만 색. 누를 수 없는 카드는 그림자 없이 평평(→ 보안 안내가 버튼처럼 안 보임)
- 홈 메뉴·보안 안내: 큰 파스텔 면 → 흰 카드 + 작은 색 원. 로그인: 휴대폰 인증 녹색 / 신분증 흰 카드(설명 '주민등록증·운전면허증 (준비 중)' 추가해 구조 통일) / 도움받기 면 없음
- 모양 규칙 `--radius-card(18)` 카드·말풍선·시트 / `--radius-control(12)` 버튼·입력칸·선택지(대화 입력칸 알약 → 통일) / `--radius-pill` 필터·칩·배지. 예전 `--radius`, `--radius-lg` 제거
- 카드 경계는 약한 그림자 하나. 아바타의 흰 테두리+그림자 겹침 제거, 위치 동의 카드의 하늘색 면 → 흰 카드
- 상태: 눌림 `--pressed-filter`(버튼·카드·탭·선택지·메뉴), 비활성은 투명도 대신 회색 면+글자 6.5:1(`--color-disabled-*`), 선택은 녹색
- 관심사 칩: 녹색 → 중립(베이지) — 녹색은 선택 상태에만
- 줄바꿈: 제목 `text-wrap: balance`, 문장 `pretty` (마지막 줄 한 단어 방지)
- 대비 확인: 아이콘 색/원 배경 4.1~7.5(비텍스트 3:1↑), 비활성 6.5, 보조 글자/흰 카드 10.9. 고대비 모드는 테두리로 구분 확인
- 하단 메뉴 선택 표시는 이미 녹색 글자+옅은 녹색 배경(시안의 노란 테두리는 구현에 없음)
