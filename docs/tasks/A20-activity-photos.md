# A20. 지역생활 활동에 실제 사진

| 영역 | 크기 | 우선 | 상태 | 브랜치 |
|---|---|---|---|---|
| 폴리싱 | S | P1 | ✅ | `polish/activity-photos` (PR #5) |

## 왜
활동 썸네일이 종류별 아이콘이라 실제 복지관·주민센터 프로그램이라는 느낌이 약했다.

## 기준
- 활동 종류(걷기·스마트폰·영화·차·노래·그림·운동·책·텃밭·도시락·줍깅)마다 사진 1장
- API 발급 없이 무료 사진(Unsplash) 주소를 바로 사용 — 프로토타입 한정
- 사진을 못 불러오면 기존 아이콘 + 색으로 대체 (봉사 상세는 A19 인물 장면)

## 손댄 곳
- `features/activity/components/activityPhotos.ts` — 종류 → 사진 한 곳에서 관리 (바꿀 때 id만 교체)
- `ActivityThumb` — 사진 위에 깔고, 불러오는 동안·실패 시 아이콘

## 완료 기준
- [x] 목록·상세 모두 사진, 실패 시 아이콘
- [x] lint·build·CI

## 진행 기록
- 실제 서비스에서는 복지관이 올린 프로그램 사진으로 교체 (`docs/ux-changes.md` 3번)
- 사진 고르기는 설명(alt) 기준으로 함 — 서양인 위주 사진이 섞여 있을 수 있어 화면 확인 후 교체 권장
