# A5. 입력칸 옆 음성 입력(받아쓰기) 버튼

| 영역 | 크기 | 우선 | 상태 | 브랜치 |
|---|---|---|---|---|
| 폴리싱 | M | P1 | ⬜ 대기 | `polish/A5-voice-input` |

## 왜
보고서: 모든 텍스트 입력 위치에 음성 입력 버튼을 동등하게 배치.

## 손댈 곳
shared/ui/TextField·TextArea, chat Composer, STT(C2) 또는 Web Speech API

## 완료 기준
- [ ] 브라우저 음성 인식 지원 시 바로 사용, 미지원 시 버튼 숨김
- [ ] 인식 중 상태가 크게 보임
- [ ] 인식 결과는 바로 보내지 않고 입력칸에 채워 확인 후 보내기

## 참고
C2와 함께 진행하면 서버 STT로 정확도 개선
