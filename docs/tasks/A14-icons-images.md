# A14. 아이콘·이미지 크기 규칙 (디자인 리뷰 3단계)

| 영역 | 크기 | 우선 | 상태 | 브랜치 |
|---|---|---|---|---|
| 폴리싱 | S | P1 | ✅ 완료 | `polish/A14-icons-images` |

## 왜
[디자인 리뷰 v1](../design/review-v1.md) 공통 14~18·21, ①-1~6, ⑥-4~6. 아이콘 크기·선 굵기, 아바타·썸네일 크기가 화면마다 달라 통일감이 약하다. 시작 화면은 로고·이름·풍경이 모두 크게 경쟁한다.

## 손댈 곳
tokens(아이콘·아바타·썸네일 크기), `Avatar`, `TopBar`, `MenuList`, 활동 썸네일, WelcomePage, Brand

## 완료 기준
- [x] 기능 아이콘 24–28 한 크기·한 선 굵기(lucide strokeWidth 통일), 조작 영역은 여백으로 48↑
- [x] 상단 바: 뒤로·오른쪽 조작의 크기·여백 동일, 오른쪽 유무와 관계없이 제목 위치 고정
- [x] 꺾쇠(›)는 목록 이동에만 작게, 주요 버튼의 화살표는 필요한 곳만
- [x] 아바타 크기 역할별: 목록 56–64 · 대화 상단 48 · 대화 말풍선 40 · 마이페이지 72
- [x] 큰 글자(4단계)에서 썸네일·아바타·로고는 글자만큼 커지지 않게 (상한) — A12에서 발견
- [x] 활동 썸네일 목록용 크기·비율·모서리 통일, 상세 상단 이미지 화면 높이 20–25%
- [x] 시작 화면: 로고+앱 이름 중심, 풍경은 낮은 강조, 시작 버튼 주변 여백, 버튼은 공통 주요 버튼과 같은 모양

## 진행 기록

- 아이콘 규칙 `shared/ui/icon.ts` — `ICON.md 26`(기능)·`sm 20`(꺾쇠)·`lg 56`(안내 그림)·`inline 1em`(글자 옆 핀·경고), 선 굵기 `ICON_STROKE 2` 하나. 기능 아이콘은 글자 크기와 무관하게 고정, 누르기 쉬움은 56px 터치 영역으로. 모든 lucide 사용처 교체
- 상단 바 오른쪽 동작을 `shared/ui/IconAction`(아이콘 26 + 짧은 글자, 56×56)으로 통일 — 설정(마이페이지, 글자 '설정' 추가)·더보기(대화)·관심(활동 상세)
- 관심 버튼: 글자는 늘 '관심', 선택은 채운 하트 + `aria-pressed` → 폭·위치가 바뀌지 않음 (e2e도 aria-pressed로 확인)
- 뒤로가기: 꺾쇠 그림이 화면 정렬선에 닿도록 아이콘 여백만큼 당김
- 꺾쇠는 목록 이동에만 20px·보조 색. 주요 버튼의 화살표 제거(시작하기·신청하기)
- 아바타 역할별 고정 크기 `bubble 40 / header 48 / list 56 / profile 72`(이름 글자는 지름의 0.34). 예전 em 단위(md/lg/xl) 제거 → 큰 글씨에서 아바타가 글자 칸을 밀지 않음. 홈 인사말 옆 아바타도 목록 크기로 낮춤(리뷰 ③-5)
- 활동 썸네일: 목록 64px 고정, 상세 상단 `clamp(140px, 22vh, 200px)` (화면 높이 ~22%)
- 시작 화면: 로고를 감싼 흰 사각 틀·그림자 제거, 로고+앱 이름 중심, 언덕은 옅은 한 색·낮은 높이로, 시작 버튼 위아래 여백 확보. 로고 글자 크기 상한 64px
- 로그인 화면 하단의 반복 로고 제거(리뷰 ②-6)
- 확인: 글자 1·4단계 캡처, e2e 22개(320px+아주 크게 포함) 통과
