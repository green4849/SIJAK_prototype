# A14. 아이콘·이미지 크기 규칙 (디자인 리뷰 3단계)

| 영역 | 크기 | 우선 | 상태 | 브랜치 |
|---|---|---|---|---|
| 폴리싱 | S | P1 | ⬜ 대기 | `polish/A14-icons-images` |

## 왜
[디자인 리뷰 v1](../design/review-v1.md) 공통 14~18·21, ①-1~6, ⑥-4~6. 아이콘 크기·선 굵기, 아바타·썸네일 크기가 화면마다 달라 통일감이 약하다. 시작 화면은 로고·이름·풍경이 모두 크게 경쟁한다.

## 손댈 곳
tokens(아이콘·아바타·썸네일 크기), `Avatar`, `TopBar`, `MenuList`, 활동 썸네일, WelcomePage, Brand

## 완료 기준
- [ ] 기능 아이콘 24–28 한 크기·한 선 굵기(lucide strokeWidth 통일), 조작 영역은 여백으로 48↑
- [ ] 상단 바: 뒤로·오른쪽 조작의 크기·여백 동일, 오른쪽 유무와 관계없이 제목 위치 고정
- [ ] 꺾쇠(›)는 목록 이동에만 작게, 주요 버튼의 화살표는 필요한 곳만
- [ ] 아바타 크기 역할별: 목록 56–64 · 대화 상단 48 · 대화 말풍선 40 · 마이페이지 72
- [ ] 큰 글자(4단계)에서 썸네일·아바타·로고는 글자만큼 커지지 않게 (상한) — A12에서 발견
- [ ] 활동 썸네일 목록용 크기·비율·모서리 통일, 상세 상단 이미지 화면 높이 20–25%
- [ ] 시작 화면: 로고+앱 이름 중심, 풍경은 낮은 강조, 시작 버튼 주변 여백, 버튼은 공통 주요 버튼과 같은 모양
