# A21. 활동 동네 선택과 위치 다시 확인

| 영역 | 크기 | 우선 | 상태 | 브랜치 |
|---|---|---|---|---|
| UX | S | P1 | GPS 경로는 main 반영 (PR #9), 수동 입력 경로는 이번 변경 | `codex/manual-neighborhood` |

## 왜
가입 화면에서 위치 권한을 거부하거나 조회가 지연되면 가입을 마칠 수 없었다. 정확한 주소 없이 동네를 정할 수 있도록 직접 입력 경로를 더한다.

## 기준
- 가입: `휴대폰 위치로 찾기`와 `동네 직접 입력` 중 선택한다.
- 위치를 찾으면 시·도와 동네 이름을 저장하고, 좌표는 약 1km 단위로 줄여 저장한다.
- 위치 권한 거부·조회 실패 시 직접 입력을 보여 준다. 시·도와 시·군·구·읍·면·동 이름으로 가입하고 좌표는 저장하지 않는다.
- 직접 입력한 회원은 같은 동네 이름의 이웃을 먼저 보되, 확인할 수 없는 거리 숫자는 표시하지 않는다.
- 마이페이지 `위치 다시 확인`으로 GPS 위치를 갱신할 수 있다.

## 손댄 곳
- `features/auth/components/LocationAgreement` — 두 지역 선택 방법과 조회 실패 후 직접 입력
- `features/auth/lib/locateRegion` — 위치 → 시·도 + 동네 이름 (OpenStreetMap 역지오코딩, 실패 시 시·도 중심점 어림). 바깥 서비스에는 소수 2자리(≈1.1km)로 줄인 좌표만 보낸다.
- `auth.users.area_name` — 동네 이름 저장. 직접 입력 시 좌표는 없음.
- `features/auth/hooks/useLocationRecheck` + `pages/MyPage` — 위치 다시 확인
- `SignupProfileForm`·`ProfileEditForm`·`HelpPage` 문구
- e2e: 동의 흐름 / 역지오코딩 실패 / 권한 거부 / 위치 다시 확인 / 바깥으로 보내는 좌표가 소수 2자리인지(H38)
