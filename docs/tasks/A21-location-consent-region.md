# A21. 사는 곳 = 위치 정보 수집 동의 (+ 마이페이지 위치 다시 확인)

| 영역 | 크기 | 우선 | 상태 | 브랜치 |
|---|---|---|---|---|
| UX | S | P1 | 🔨 PR 리뷰 대기 | `feat/region-from-location` (PR #9) |

## 왜
가입 화면의 시·도 17개 버튼이 길고 투박했다. 동네 서비스에서 익숙한 '위치 동의 한 번'으로 대신한다.

## 기준
- 가입: 시·도 선택·'내 위치로 찾기' 버튼 없음 → **위치 정보 수집 동의** 체크 한 줄
- 동의하면 바로 위치를 읽어 동네 이름 표시, 서버에는 시·도 코드만 (API 변경 없음)
- 위치를 못 읽으면 동의 해제 + 안내 → 동의 없이는 가입 불가 (정책: 위치 동의 필수)
- 동의한 위치는 '같은 동네' 이웃 찾기용으로도 저장 → 다시 묻지 않음
- 프로필 수정에서 사는 곳 삭제, 대신 마이페이지 **위치 다시 확인** (이사 대응)

## 손댄 곳
- `features/auth/components/LocationAgreement` — 동의 카드 (줄 전체가 터치 영역, 실제 체크박스는 낭독기용)
- `features/auth/lib/locateRegion` — 위치 → 시·도 + 동네 이름 (OpenStreetMap 역지오코딩, 실패 시 시·도 중심점 어림)
- `features/auth/hooks/useLocationRecheck` + `pages/MyPage` — 위치 다시 확인
- `SignupProfileForm`·`ProfileEditForm`·`HelpPage` 문구
- e2e: 동의 흐름 / 역지오코딩 실패 / 권한 거부 / 위치 다시 확인
