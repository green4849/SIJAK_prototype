## 왜
보고서 3.1 표 '인지 강화 기능 — 기억력·주의집중 향상 게임'. 로드맵에 항목이 없어 새로 만듦.

## 이번에 한 것 — 화면·시연 데이터 (백엔드 없음, docs/deferred.md §7)
- 홈 아래 '오늘의 두뇌 운동' 카드 (연속 일수) → `/brain`: 이번 주 한 날(월~일), 게임 두 개(최고 기록)
- **짝 맞추기** `/brain/match`: 카드 8장(그림 4쌍), 그림 옆 이름 글자, 틀리면 1.1초 보여 주고 덮기, 뒤집은 횟수
- **셈하기** `/brain/calc`: 한 자리 덧셈·뺄셈 5문제, 큰 숫자 버튼 4개, 바로 맞음/틀림(글자+색+취소선)
- 끝나면 기록 저장 → 연속 일수 갱신. 데모 시드: 어제까지 사흘 연속
