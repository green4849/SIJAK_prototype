| 영역 | 크기 | 우선 | 상태 | 브랜치 |
|---|---|---|---|---|

## 왜
신고가 쌓이기만 한다.

## 손댈 곳
별도 admin 앱 또는 보호된 /admin

## 완료 기준

- [ ] 경고·정지·해제 처리 기록
- [ ] 운영자 권한 분리

## 이번에 한 것 — 화면·시연 데이터 (백엔드 없음, docs/deferred.md §7)
- `/admin` (어르신 화면에는 들어가는 길 없음 — 주소로 직접): 같은 앱 안 보호 라우트 방식
  - **신고·위험 대화**: 처리 전이 위로·위험도 순, 대상·이유·문제 메시지 일부, 경고 / 7일 정지 / 영구 제한 / 문제없음
  - 데모 안에서 이웃을 신고하면 바로 이 목록에 들어온다
  - **돌봄이 필요한 이웃** (복지기관용): 고립 지수 높은 순, 최근 신호, 마지막 접속, 보호자 알림 여부 (보고서 4.5.3 '지역 복지기관 모니터링')
- [ ] 백엔드: 운영자 역할·권한, 처리 이력, 정지 상태를 로그인·대화에 반영
