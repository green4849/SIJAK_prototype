# B9. 다중 서버 요청 제한 저장소 (Redis)

| 영역 | 크기 | 우선 | 상태 | 브랜치 |
|---|---|---|---|---|
| 실서비스 필수 | S | P1 | ⏸ 서버 1대·워커 1개에서 보류 | `prod/B9-external-session` |

## 왜
운영 카카오 로그인은 JWT 토큰으로 처리한다. 요청 횟수 제한(`core/ratelimit.py`)은 프로세스 메모리라 서버를 여러 대·워커 여러 개로 늘릴 때 공용 저장소가 필요하다.

## 손댈 곳
