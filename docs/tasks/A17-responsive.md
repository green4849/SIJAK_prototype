# A17. 기기 크기에 맞는 화면 (휴대폰·태블릿·PC)

| 영역 | 크기 | 우선 | 상태 | 브랜치 |
|---|---|---|---|---|
| 폴리싱 | M | P1 | ✅ 완료 | `polish/A17-responsive` |

## 왜
지금까지는 휴대폰 폭(320~560px)에만 맞춰져, 태블릿·PC에서는 가운데 560px 기둥에 양옆이 비었다. 어르신은 태블릿을 많이 쓴다.

## 손댈 곳
`tokens.css`(유동 글자·여백·화면 폭), `AppLayout`, `shared/ui/CardGrid`(신설), 친구·활동 목록, 홈, 마이페이지, 대화 말풍선

## 완료 기준
- [x] 화면 폭에 따라 기본 글자(18→20px)·좌우 여백(20→32px)이 연속적으로 커짐. 사용자 글자 단계는 그 위에 곱해짐
- [x] 목록 화면(홈·친구·지역생활·마이페이지)은 최대 960px, 읽고 쓰는 화면(대화·폼·상세)은 최대 640px
- [x] 카드 목록: 휴대폰 1열, 태블릿 세로 2열, 큰 글씨(4단계)에서는 다시 1열 — 기기 이름이 아니라 남는 폭으로 결정
- [x] 홈 메뉴: 세 개가 한 줄에 들어갈 폭(PC·태블릿 가로)에서만 3열 — 2+1로 어색하게 나뉘지 않게
- [x] 기존 휴대폰 화면·접근성 스윕(320px 포함) 그대로 통과

## 진행 기록

- 글자 크기 단계를 px 고정값(21/24/28) → 배율 `--font-scale`(1.17/1.33/1.56)로 바꿔, 유동 기본 글자 `clamp(18px, 16px + 0.5vw, 20px)` 위에 곱해지게
- `--gutter: clamp(20px, 4vw, 32px)`, `--page-max 640` / `--page-max-wide 960` / `--card-min 17rem`(rem 이라 글자가 커지면 카드 최소 폭도 커져 자동 1열)
- `shared/ui/CardGrid` — `repeat(auto-fill, minmax(min(100%, --card-min), 1fr))`. 미디어 쿼리 없이 남는 폭으로 열 수 결정. `as="ul"`, `gap="section"` 지원
- 적용: 받은 친구 신청·추천/같은 동네·내 친구 목록·지역 활동 목록(카드 2열), 마이페이지 두 메뉴 묶음(나란히), 탭 화면은 `TabLayout` 넓은 폭
- 홈 메뉴는 본문 폭 컨테이너 쿼리(`@container page (min-width: 44rem)`)로 3열 — 창 크기가 아니라 본문 폭 기준
- 말풍선 최대 폭 `min(78%, 32rem)` — 넓은 화면에서 한 줄이 지나치게 길어지지 않게
- 장소처럼 여러 줄로 넘어가는 글 옆 아이콘이 줄어들거나 가운데로 밀리던 문제 수정(첫 줄 가운데 고정)
- 화면 캡처 도구에 태블릿(820px) 추가 — `t-*.png`. PC(1280px)는 수동 확인
