# A4. 동작 후 피드백 — 토스트·진동

| 영역 | 크기 | 우선 | 상태 | 브랜치 |
|---|---|---|---|---|
| 폴리싱 | S | P1 | ⬜ 대기 | `polish/A4-action-feedback` |

## 왜
보고서 UI 원칙 '직접적 피드백'. 지금은 저장·신청·수락 후 화면만 바뀌어 성공했는지 알기 어렵다.

## 손댈 곳
shared/ui/Toast (신설), 주요 동작(프로필 저장·친구 신청/수락·활동 신청/취소·신고·차단)

## 완료 기준
- [ ] 큰 글씨 토스트가 화면 아래에 3~4초, 화면 낭독기도 읽음(role=status)
- [ ] 지원 기기에서 짧은 진동 (설정에서 끌 수 있음)
- [ ] 같은 토스트가 쌓이지 않음
- [ ] e2e에서 토스트 확인
