# A12. 글자 체계·여백 정리 (디자인 리뷰 1단계)

| 영역 | 크기 | 우선 | 상태 | 브랜치 |
|---|---|---|---|---|
| 폴리싱 | M | P1 | 🔨 진행 중 | `polish/A12-type-spacing` |

## 왜
[디자인 리뷰 v1](../design/review-v1.md) 공통 1~7. 제목은 Jua, 본문은 Noto라 화면 인상이 갈리고, 설명·버튼까지 굵어(700~800) 제목·본문 위계가 약하다. 여백도 화면마다 제각각.

## 손댈 곳
`shared/styles/tokens.css`(역할별 글자 크기·굵기·여백 토큰), `base.css`, `shared/ui/*`, 각 화면 CSS의 크기·굵기·여백을 토큰으로 교체. 로고(`Brand`)만 Jua 유지

## 완료 기준 (390px 프레임, 글자 1단계 기준 — 4단계는 비례)
- [ ] 글꼴 통일: 로고 외 제목·본문·버튼·숫자 모두 Noto Sans KR
- [ ] 굵기 3단계만: 본문 400 · 메뉴/버튼 500 · 제목 600 (700↑는 로고·숫자 강조 예외만)
- [ ] 역할별 크기 토큰: 화면 제목 24–28 · 카드 제목 20–22 · 본문 18–20 · 보조 16–18 · 하단 메뉴 14–16
- [ ] 본문 줄 간격 1.4–1.6, 제목 1.3
- [ ] 화면 좌우 여백 20–24, 카드 내부 16–20, 카드 사이 12–16 — 모두 토큰
- [ ] 화면 제목·설명·필터·카드의 왼쪽 정렬선 하나로 (가운데 정렬 설명문 정리)
- [ ] 관련 요소는 가깝게, 묶음 사이는 멀게 (간격 규칙을 토큰 주석에 기록)
- [ ] 글자 4단계·좁은 화면(320px)에서 잘림·겹침 없음 (a11y e2e + 캡처 확인)
