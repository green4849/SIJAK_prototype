# A12. 글자 체계·여백 정리 (디자인 리뷰 1단계)

| 영역 | 크기 | 우선 | 상태 | 브랜치 |
|---|---|---|---|---|
| 폴리싱 | M | P1 | ✅ 완료 | `polish/A12-type-spacing` |

## 왜
[디자인 리뷰 v1](../design/review-v1.md) 공통 1~7. 제목은 Jua, 본문은 Noto라 화면 인상이 갈리고, 설명·버튼까지 굵어(700~800) 제목·본문 위계가 약하다. 여백도 화면마다 제각각.

## 손댈 곳
`shared/styles/tokens.css`(역할별 글자 크기·굵기·여백 토큰), `base.css`, `shared/ui/*`, 각 화면 CSS의 크기·굵기·여백을 토큰으로 교체. 로고(`Brand`)만 Jua 유지

## 완료 기준 (390px 프레임, 글자 1단계 기준 — 4단계는 비례)
- [x] 글꼴 통일: 로고 외 제목·본문·버튼·숫자 모두 Noto Sans KR
- [x] 굵기 3단계만: 본문 400 · 메뉴/버튼 500 · 제목 600 (700↑는 로고·숫자 강조 예외만)
- [x] 역할별 크기 토큰: 화면 제목 24–28 · 카드 제목 20–22 · 본문 18–20 · 보조 16–18 · 하단 메뉴 14–16
- [x] 본문 줄 간격 1.4–1.6, 제목 1.3
- [x] 화면 좌우 여백 20–24, 카드 내부 16–20, 카드 사이 12–16 — 모두 토큰
- [x] 화면 제목·설명·필터·카드의 왼쪽 정렬선 하나로 (가운데 정렬 설명문 정리)
- [x] 관련 요소는 가깝게, 묶음 사이는 멀게 (간격 규칙을 토큰 주석에 기록)
- [x] 글자 4단계·좁은 화면(320px)에서 잘림·겹침 없음 (a11y e2e + 캡처 확인)

## 진행 기록

- 토큰(`shared/styles/tokens.css`) 역할별로 재정의 — 크기 `--text-title/card-title/button/body/meta/nav/hero`, 굵기 `--weight-regular/medium/semibold/bold`, 줄 간격 `--leading-body(1.55)/title(1.3)`, 여백 `--gutter(20)/card-pad(18)/card-gap(12)/section-gap(24)/gap-tight(4)`. 예전 `--font-sm/lg/xl` 은 없앰(남은 사용처 0 확인)
- 글꼴: `--font-ui`(Noto) 하나로, Jua(`--font-brand`)는 Brand 로고 글자만. Noto 800 대신 600 파일 로드
- 굵기: 버튼·탭·메뉴·칩 500, 제목·이름·입력칸 이름 600, 700은 빨간 숫자 배지만. 하단 탭 선택 시 굵기 변화 없앰(글자 폭 흔들림) → 색+배경으로만
- 정렬선: `TopBar` 를 왼쪽 정렬 큰 제목으로 — 뒤로가기 있으면 [뒤로 … 오른쪽 동작] 아래 제목, 탭 화면은 [제목 … 오른쪽 동작]. `description` prop으로 제목 바로 아래 설명(친구 찾기·지역생활). 로그인·보안 안내·안내형 화면의 가운데 정렬 제목·설명도 왼쪽으로. 시작 화면(브랜드)·빈 목록 안내만 가운데 유지
- 고정 막대(신청 버튼·입력줄·토스트·끊김 안내·데모 띠)도 좌우 `--gutter` 로 본문과 같은 선
- 폼 제목·설명은 같은 묶음 안에서 `--gap-tight`
- a11y 스윕에 '좁은 화면 320px + 아주 크게' 추가 — 전 화면 넘침·작은 터치 영역 없음
- 화면 캡처 도구 `e2e/screens.spec.ts`(SCREENS=1)로 전후 비교
- 남은 것 → A14: 글자 4단계에서 활동 썸네일·마이페이지 아바타·홈 로고가 em 단위로 같이 커져 글자 폭을 좁힘 (크기 규칙 작업)
