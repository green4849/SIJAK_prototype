# A1. 하단 탭·홈 카드에 안 읽은 메시지·받은 친구 신청 배지

| 영역 | 크기 | 우선 | 상태 | 브랜치 |
|---|---|---|---|---|
| 폴리싱 | S | P1 | ⬜ 대기 | `polish/A1-unread-badges` |

## 왜
새 메시지·친구 신청이 와도 해당 화면에 들어가야만 알 수 있다.

## 손댈 곳
app/BottomNav, pages/HomePage, features/chat·friend 개수 훅, shared/ui/Badge

## 완료 기준
- [ ] 홈 '대화하기' 카드에 안 읽은 메시지 수, '친구 찾기' 카드·친구 탭에 받은 신청 수
- [ ] 화면 낭독기가 '친구, 새 친구 신청 1개'처럼 읽는다 (숫자만 읽히지 않게)
- [ ] 폴링은 화면 수와 관계없이 한 번만 (같은 데이터를 여러 곳에서 써도 요청 중복 없음)
- [ ] 대화방을 읽고 나오면 배지가 바로 줄어든다
- [ ] 99개 초과는 99+
- [ ] e2e 추가
