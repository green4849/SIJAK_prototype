# A23. 지역생활 카드 정렬 — 같은 줄 카드 높이 맞춤

| 영역 | 크기 | 우선 | 상태 | 브랜치 |
|---|---|---|---|---|
| 폴리싱 | S | P1 | ✅ | `polish/activity-card-align` |

## 왜
태블릿·PC처럼 활동 카드가 두 줄로 놓일 때, '마감'·'신청했어요'·'+100P' 표시가 붙은 카드만 아래로 길어져 같은 줄 카드의 끝선이 들쭉날쭉했다.
오른쪽 화살표(>)도 카드마다 세로 가운데에 놓여서, 옆 카드끼리 화살표 높이가 어긋났다(최대 약 30px).

## 바뀐 것 (사용자 관점)
- 같은 줄의 카드는 높이가 같다. 짧은 카드가 옆 카드 높이만큼 늘어난다.
- 그래서 카드 끝선과 오른쪽 화살표 높이가 줄마다 가지런하다.
- 휴대폰(한 줄)에서는 달라진 것이 없다.
- 지역생활 목록과 마이페이지 '내 활동' 목록에 같이 적용된다(같은 목록을 쓴다).

## 완료 기준
- [x] 1000px 폭에서 같은 줄 카드 높이·화살표 높이 일치 확인
- [x] 휴대폰 폭은 그대로
- [x] typecheck·lint·build, CI e2e

## 진행 기록
- 카드 목록 틀에 이미 있던 '같은 줄 높이 맞춤'(메뉴·안내 카드용)을 활동 목록에도 켰다
- 참고: 선택한 분류 칩 둘레의 주황 테두리는 지금 위치를 보여 주는 포커스 표시라 그대로 둔다
