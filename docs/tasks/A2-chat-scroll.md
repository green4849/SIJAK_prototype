## 진행 기록

- `features/chat/hooks/useStickToBottom`: 스크롤 위치를 기억해 두고, 새 메시지가 그려진 직후(useLayoutEffect) 판단 → 깜빡임 없음
- 처음 열 때·내가 보낼 때·맨 아래 근처(화면 절반 이내)면 따라 내려감, 아니면 '새 메시지 N개 ↓' (입력줄 바로 위, 움직임 줄이기 설정 존중)
- **함께 고친 버그:** 기존 `scrollIntoView`가 목록 끝을 화면 끝에 맞춰 **마지막 말풍선이 아래 고정 입력줄에 가려짐** → 문서 끝까지 스크롤로 변경, e2e에 가림 검사 추가
- `<ol>` 안의 `<div>`(잘못된 마크업) 제거
- e2e `chat-scroll.spec.ts`
