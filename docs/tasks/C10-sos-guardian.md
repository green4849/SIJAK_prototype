## 이번에 한 것 — 화면·시연 데이터 (백엔드 없음, docs/deferred.md §7)
- 홈 오른쪽 위 **긴급** (빨강, 아이콘+글자) — 홈 인사 옆 내 얼굴 그림 자리를 씀 (얼굴은 마이페이지에)

- 말동무 위기 안내에 '보호자에게 알리기' (확인 없이 바로)
- 데모: 아들 김민수, 담당 복지사 박선희
