# A19. 친근한 일러스트 되살리기 (처음 시안의 약 40%)

| 영역 | 크기 | 우선 | 상태 | 브랜치 |
|---|---|---|---|---|
| 폴리싱 | M | P1 | ✅ | `polish/A19-friendly-illustrations` |

## 왜
폴리싱(A12~A18)으로 읽기 쉬워졌지만 처음 유저플로우 시안의 따뜻하고 친근한 느낌이 많이 빠졌다.
디자인 리뷰 공통 15("인물·풍경은 친근한 일러스트로 유지하되, 조작 요소는 간결한 아이콘으로")의 범위 안에서 되살린다.

## 기준
- **가져온다**: 인물 일러스트(아바타), 풍경 속 인물 장면 — 글자 없이, 장식(aria-hidden)
- **되돌리지 않는다**: 메뉴 카드의 큰 파스텔 면(공통 10), 줄인 글씨(A18), 대비 7:1, 터치 영역, 기능 아이콘 규칙(공통 14·15), 활동 썸네일 통일(⑥-5)
- 크기는 역할별로 고정(공통 16) — 글자 크기 설정과 무관, 선명한 화면에서는 풍경 띠를 숨기고 인물만

## 손댄 곳
- `shared/ui/illustrations/` — `Senior`(머리·어깨 인물: 할머니 3·할아버지 3 머리 모양, 안경, 옷 4색), `Scenes`(이웃 인사·노부부·시작 언덕), `look.ts`(id로 모습 고정)
- `shared/ui/Avatar` — 이름 글자 → 얼굴 일러스트 (같은 크기·같은 원 배경)
- 배치: ① 시작(언덕 위 작은 노부부) · ③ 홈(인사 아래 이웃 풍경 띠) · ⑧ 안전 안내 · 포인트 부족 시트 · 빈 목록(추천 친구·대화)
- 2차: ⑥ 봉사 탭 위 풍경 띠(줍깅·도시락 나눔) · ⑦ 봉사 상세 상단(도시락 나눔·줍깅 장면, 그 밖의 활동은 아이콘 유지) · 내 포인트 잔액 옆(동전 든 할머니) · 알림 설정 위(휴대폰·종·달)
- `tokens.css` — `--illust-*` 색 (일러스트 전용)
- API: `ChatPeer`·`BlockedUser` 에 `gender` (아바타 그림 구분용) — 데모 핸들러도 같이

## 진행 기록
- 그림체: 갈색 선(#5a4632) + 연한 면, 웃는 눈·볼 터치 — 처음 시안의 인물과 같은 분위기, 원본 그림은 쓰지 않고 자체 벡터
- 선명한 화면: 인물은 밝은 면이라 갈색 선 그대로(눈·입이 보이게), 풍경 띠·언덕은 숨김
- 대화 목록 빈 화면의 두 번째 문장도 대본으로 옮김 (A18 기준)
- 2차: 봉사·포인트·알림 화면에도 같은 그림체 (시안 반응이 좋아서). 손이 떠 보이지 않게 소매(옷 색 굵은 선 + 갈색 테두리)로 어깨와 연결. 목록 썸네일은 아이콘 통일 유지(리뷰 ⑥-5)
- PR #3 이 main 이 아니라 이미 머지된 A18 브랜치로 들어가 데모에 빠져 있었음 → PR #6 으로 main 반영 (활동 사진 A20 과 겹친 썸네일은 사진 우선, 실패 시 장면/아이콘)
- 넓은 화면에서 홈·봉사 배너 인물 머리 잘림 → 하늘·언덕(가로로 늘림)과 인물(비율 유지·가운데) 층을 나눔 (PR #7)
