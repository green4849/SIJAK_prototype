# A18. 화면 글씨 줄이기 — 설명은 시연 대본으로

| 영역 | 크기 | 우선 | 상태 | 브랜치 |
|---|---|---|---|---|
| 폴리싱 | S | P1 | 🔨 PR 리뷰 대기 | `polish/A18-less-text` |

## 왜
글씨를 키워 써야 하는 어르신 화면에 젊은 세대 앱보다 글씨가 많았다. 부제·카드 설명·사용 안내 같은 작은 글씨가 화면마다 있어 정작 눌러야 할 것이 묻힌다.

## 기준
- **지운다**: 제목만 봐도 아는 부제·카드 설명, "누르는 즉시 바뀌어요" 같은 사용 안내, 보조 설명 줄
- **남긴다**: 이름·나이·일정·장소·포인트 숫자, 위험 대화 경고, 위치 저장 범위(한 줄), 설명이 곧 내용인 화면(도움말·홈 화면 놓기)
- 지운 문장은 버리지 않고 [`docs/demo-script.md`](../demo-script.md) 에 화면 순서대로 — 시연 영상 내레이션·자막용

## 완료 기준
- [x] 전 화면 작은 설명 글씨 삭제·축약 (①②⑧③④⑤⑥⑦⑨ + C12 화면)
- [x] 지운 문장 전부 시연 대본으로
- [x] 남는 CSS 정리, e2e 문구 갱신, lint·build·e2e(접근성 스윕 포함)

## 진행 기록
- 화면 글씨: 33개 파일에서 158줄 삭제 / 33줄 추가. 홈 카드 설명·친구 찾기·지역생활 상단 설명·로그인 안내·가입 안내·설정 힌트 4개·평가 안내·미션 설명·포인트 보조 줄 등
- 줄인 것: 안전 안내 카드(한 줄씩 짧게), 알림 설정 제목, 대화 주제 버튼('대화 주제 추천'), 진행 표시('3명 중 1명'), 관심사 개수('2 / 5개'), 태어난 해 예시는 입력칸 자리표시로
- 활동 한 줄 소개(`subtitle`)는 데이터는 그대로, 상세 화면에서만 숨김
