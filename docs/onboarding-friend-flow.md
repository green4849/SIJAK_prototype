# 가입부터 동네 친구까지의 첫 이용 흐름

## 목표 순서

1. **카카오 로그인 및 회원가입** — 카카오 계정으로 로그인하고, 신규 회원은 이름·생년월일·성별을 직접 입력한 뒤 필수 약관에 동의한다. 본인확인은 진행하지 않는다.
2. **활동 지역 설정** — 정확한 주소를 입력하거나 보여 주지 않고 동네 수준으로 확인.
3. **시작이와 성향조사** — 관심사 → 생활 방식 → 관계 성향. 처음 고른 관심사는 조사 첫 문항에 이어서 사용.
4. **맞춤형 동네 친구 추천** — 성향과 지역을 바탕으로 추천 이유를 함께 표시.
5. **프로필 확인 및 행동 선택** — 추천 상대의 정보를 확인한 뒤 `친구 신청하기` / `다른 친구 보기` / `나중에 보기` 중 선택. 사용자 확정 문구.
6. **마음 척도(WHO-5) 선택** — 친구 찾기 흐름 뒤에 제안하며, 하지 않아도 홈으로 진행. 결과는 친구 추천에 사용하지 않음.

## 현재 구현과 확인할 일 (2026-11-28)

| 목표 | 현재 구현 | 확인할 부분 |
|---|---|---|
| 1. 로그인·가입 | 운영 화면은 카카오 로그인만 표시한다. 신규 회원은 이름·생년월일·성별과 약관을 직접 입력·동의한다. 시연 빌드는 Mock 로그인 | 실제 카카오 계정으로 가입을 끝까지 확인. 카카오 로그인은 본인확인이 아님 |
| 2. 지역 | 가입 3/3단계에서 위치 동의 후 동네 이름을 보여 주고 좌표를 약 1km 단위로 저장 | 운영 화면에서 위치 조회 지연 안내가 관찰됨. 위치 조회가 안 될 때의 가입 경로 점검 |
| 3. 성향조사 | 가입 완료 후 `/friends/survey?welcome=1`로 바로 연결. 관심사부터 8문항 | 실제 기기에서 질문 흐름 확인 |
| 4. 추천 | 조사 완료 뒤 지역·성향 추천으로 연결하고 이유를 카드에 표시 | 실제 계정에서 후보가 없을 때의 안내 확인 |
| 5. 프로필·선택 | 첫 이용 프로필 확인 창에서 `친구 신청하기` / `다른 친구 보기` / `나중에 보기`를 표시 | 실제 계정의 신청·포인트 처리 확인 |
| 6. 마음 척도 | 친구 선택 뒤 WHO-5를 제안하고 건너뛰면 홈으로 진행 | 실제 계정에서 건너뛰기·완료 확인 |

## 이동 원칙

- 친구 신청은 사용자가 5번에서 명시적으로 선택했을 때만 실행한다. 포인트가 드는 신청은 기존 확인 창을 유지한다.
- `다른 친구 보기`는 추천 목록으로 돌아가고, `나중에 보기`는 신청 없이 6번으로 진행한다.
- 마음 척도는 시작하거나 건너뛸 수 있으며, 건너뛰어도 친구 추천과 앱 이용이 막히지 않는다.
- 기존 회원의 일반 친구 탭과 마이페이지 진입은 첫 이용 안내와 구분한다.
